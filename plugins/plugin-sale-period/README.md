# App「公開の予約と販売期間」（ec-sugar/plugin-sale-period）

商品ごとに「この日時から出す」「この日時で終わる」を決める公式の App。
新商品の公開を時間で予約したり、期間限定の商品を自動で売り止めたりできる。

- **決める所**: 管理画面の商品の画面の App の欄「公開の予約と販売期間」。「ショップに公開する日時」と「販売を終える日時」を、日本時間の `2026-12-01 10:00` の形で入れる（どちらか片方だけでもよい。両方を空にして保存すると、その商品の期間をやめる）。入れた日時は UTC で置き、画面には日本時間で出す
- **期間の前**: ショップの一覧・検索・商品の画面・サイトマップ・商品フィードに出さない（核の口 `ListingVisibilityProvider`。商品の画面は 404）
- **期間の中**: ふだんどおり（この App は何もしない）
- **期間の後**: 商品の画面と一覧の札は「売り切れ」（同じ口）。カートに入らず、もうカートに入っている行は注文に進めない（核の口 `SaleHoldProvider`。お客さんには「この商品は販売期間を終えました。」と出る）。商品そのものはショップに残る
- **境界**: 出す日時の**ちょうど**に出て、終わる日時の**ちょうど**に終わる（終わりは「その日時になった瞬間から売り切れ」）。見張りの処理は無く、要求のたびに今の時刻と比べるので、秒の単位でそのとおりに変わる
- **管理画面の画面**: メニューの「App」の下の「公開の予約と販売期間」に、日時を決めた商品が出る日時の早い順に並ぶ（公開待ち・販売中・販売終了 で絞り込める）。1 件の画面からは商品へ進めて、「期間の設定を解除する」で日時を消せる。期間が終わった商品はホームの「やること」にも出る
- **核のデータは変えない**: 商品の状態（`listings.status` の `draft` / `active` / `archived`）はこの App では変わらない。期間は App の表 `sale_period_windows`（1 商品に 1 行）だけに持つ。**公開にしていない商品は、出す日時が来てもショップに出ない**（店の人が「公開」にしてから、出す日時で出る）
- **止めた店**: App を止めると期間は効かなくなり、商品はふだんどおり売れる（行は残るので、使うに戻せば元の期間に戻る）。オーナーは App の画面の「この App のデータを消す」（か `php artisan plugin:purge <店> sale-period`）で行を消せる（ADR 0092）

## ほかの App との関係

- **予約販売**（`plugin-preorder`）は発売日の前に「予約」で売る App で、この App は「出さない・売らない」。同じ商品で両方を使うと、出す日時の前は予約も受けない（出していない商品だから）
- **抽選販売**（`plugin-lottery`）と同じく、期間の外の商品は売り方を押さえた状態になる。押さえた商品は、ほかの App の 1 品の注文（チケット・定期便など）にも入らない
- **再入荷のお知らせ**（`plugin-restock`）の「入荷した」の見方は在庫で決まるので、期間の後の売り切れでは知らせを送らない

## 書き方

状態を変えるのは `SaleWindows` だけ（連鎖のロック → 行のロック → 同じトランザクションのイベント `sale_period.set`・`sale_period.cleared`）。
記録に入れるのは商品の ID と日時だけで、店の人の書いた文・個人情報は入れない。
読み出しは `SalePeriodSchedule`（「今」は PHP の時刻を値で渡し、SQL の `now()` は使わない）。
