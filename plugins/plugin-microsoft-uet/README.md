# Microsoft 広告 UET（App）

Microsoft 広告（Bing などの検索広告）から来たお客さんが、ショップのページを見たことと、購入したことを Microsoft に知らせます。広告の効果を確かめたり、もう一度見に来てもらう広告（リマーケティング）に使ったりします。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押す。一覧の「Microsoft 広告 UET」の名前（か右の「設定」）を押すと、この App の画面に入る
2. 「設定」の「UET タグ ID」に入れて、「設定を保存する」を押す
   - UET タグ ID は、Microsoft 広告の「ツール」→「UET タグ」の一覧に出る 5〜12 桁ほどの数字です
   - 数字のほかの文字（スニペットのコードなど）は入れられません。コードを貼る必要はありません
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
3. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
4. Microsoft 広告の UET タグの設定で、次の 2 つを切ってください
   - **「拡張コンバージョン（Enhanced conversions）」の自動の収集**。入れておくと、ページの入力欄からメールなどを拾おうとします（このショップでは入力欄のある画面にタグを入れませんが、念のため）
   - **「Microsoft Clarity を有効にする」**。この App からは Clarity を読みません（読もうとしても止まります）。Clarity を使うときは「Microsoft Clarity」の App を入れてください。同意の帯を出す店では、アクセスの解析の同意は、広告の同意とは別にお客さんに聞きます
5. 購入の計測は、Microsoft 広告の「コンバージョン目標」で、種類を「購入」（イベント、アクションが `purchase`）にして作ってください

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で「ページの表示（pageLoad）」を送ります
- ご注文を受け付けた画面で「購入（purchase）」を送ります。同じ画面を読み直しても、同じタブでは二度送りません（Microsoft も注文の番号で重複を除きます）
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、ブラウザと端末の情報、Microsoft の Cookie の識別子（MUID・_uetsid・_uetvid）
- 購入のとき: 注文の番号、合計の金額、通貨、品の ID と数
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。
