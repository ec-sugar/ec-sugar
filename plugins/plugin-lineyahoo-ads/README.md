# LINEヤフー広告（App）

Yahoo! JAPAN や LINE に出した広告（LINEヤフー広告）から来たお客さんが、ショップのページを見たことと、購入したことを LINEヤフーに知らせます。広告の効果を確かめたり、ショップを見た人に広告を出したり（サイトリターゲティング）するのに使います。

LINEヤフー広告の「計測タグ」（新しい形のタグ）を使います。ディスプレイ広告と検索広告（ショッピング）で使えます。LINE 広告の「LINE Tag」は LINE 広告の終了とともに使えなくなったので、この App で受けてください。

## 使い方

1. LINEヤフー広告のアカウントをビジネスマネージャーにつなぎ、ビジネスマネージャーで計測タグを発行する
2. EC-SUGAR の管理画面で店を開き、メニューの「App」を押す。一覧の「LINEヤフー広告」の名前（か右の「設定」）を押すと、この App の画面に入る
3. 「設定」の「タグ ID」に入れて、「設定を保存する」を押す
   - タグ ID は、ビジネスマネージャーの計測タグの画面で見られる、英数字とハイフンの 36 文字の ID です（例: `1a2b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d`）
   - スニペットのコードは貼れません。コードを貼る必要はありません（タグはショップが入れます）
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
4. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
5. 広告管理ツールでコンバージョン測定を作るときは、計測タグの「購入（purchase）」のイベントで数えるようにしてください

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で「ページビュー」を送ります
- ご注文を受け付けた画面で「購入」を送ります。注文の番号を付けて送るので、同じ画面を読み直しても LINEヤフーが重複として除きます
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、ブラウザと端末の情報、LINEヤフーの Cookie とローカルストレージの識別子
- 購入のとき: 注文の番号、合計の金額と通貨（金額は日本円か米ドルのときだけ）、品の ID と数（10 品まで）
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所（照合用の情報〔email・phoneNumber〕は使いません）
- **パートナー企業へは送りません**（計測タグの「パートナー企業へのデータ送信」を切っています）

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。

## できないこと

- 検索広告（ショッピング以外）の従来の「サイトジェネラルタグ」と「コンバージョン測定タグ」は入れません。LINEヤフーの案内で検索広告が計測タグに対応したら、この App で数えられます
