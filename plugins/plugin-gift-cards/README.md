# App「ギフトカード」（ec-sugar/plugin-gift-cards）

ショップで使えるギフトカード（商品券）を売る公式の App（ADR 0076）。

- 売る: `/p/gift-cards`（額面を選ぶ → 買う人の名前とメール・贈る相手のメール〔任意〕とメッセージ〔任意〕→ 最後の確認 → カードのお支払い）。会員でもゲストでも買える。送料なし・消費税なし（前払式支払手段の発行は不課税）・カード払いだけ
- 届ける: 払いが確かになったら（`PaymentConfirmed`）核にカードを発行させ、コードを買った人と贈る相手にメールで届ける（キューを通さず直に。コードは保存しない）。注文はデジタルの受渡を渡し終えて完了になる
- 見回り: 1 時間ごとの `gift-cards:issue` が、発行を落とした注文を発行し、メールの届かなかったカードのコードを出し直して送り直す（まだ使われていないカードだけ）
- 設定: 額面の選択肢（既定 3,000・5,000・10,000 円。1,000〜50,000 円で 8 つまで）、有効期限の日数（既定 180 日。1〜1095 日）

残高の帳簿・注文の入力での使い方・取消と返金での戻し方・管理画面（設定 › ギフトカード）は核（`app/Core/GiftCard`）。App をやめても、発行したカードは期限まで使える。

ショップのメニューに `/p/gift-cards` へのリンクを足すと、お客さんが買う画面にたどり着ける。
