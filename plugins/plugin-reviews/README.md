# 商品レビュー（EC-SUGAR の App）

買ったお客さんが、ショップの商品の画面に星（5 段階）と感想を書ける App です。ショップに出すかどうかはお店が決めます。
核の口（プラグインの表・App の画面・商品の画面の差し込み口・マイページとご注文の確認の入口）だけで作っています（ADR 0025・0050・0051）。

## 使い方

1. 管理画面の店のメニュー「App」から「商品レビュー」を開き、「使う」にします（運用の段階・直前の再確認）。
2. 書けるのは、その商品を買って**発送が済んだ**お客さんだけです。1 つのご注文の 1 つの商品に、1 つ書けます。
   - 会員: マイページの「レビュー」から、書けるご注文の商品を選んで書きます。
   - 会員でないお客さん: ご注文の確認の画面（確認のメールのリンク、またはご注文番号とメールでの確認）の「レビューを書く」から書きます（リンクは 24 時間有効。ご注文の確認を開き直すと新しくなります）。
3. 書かれたレビューは、管理画面のメニュー「App」の下の「レビュー」に「確認待ち」で並びます（ホームの「やること」にも件数）。読んで「公開する」か「非公開にする」を押します。
4. 1 件の画面の「直す」の欄で、店からの返信を書けます（ショップでは「ショップから」として出ます。空にして保存すると消えます）。「消す」は元に戻せません（パスキーでもう一度確認します）。
5. ショップの商品の画面の説明の下に「レビュー」が出ます。公開したレビューの平均の星と件数、新しい 20 件（最初から開いた形。JavaScript は使いません）。

- すぐにショップに出したいときは、App の設定の「レビューの公開」を「すぐに掲載する」にします（掲載した後でも非公開にできます）
- 星は 1〜5、タイトルは 50 文字、本文は 1000 文字、表示名は 20 文字まで。表示名が空なら「購入者」。HTML は使えません（書いても文字のまま出ます）
- ショップに出るのは表示名と書いた日だけです。お客さんの名前・メールアドレス・届け先は、ショップにも管理画面の App の画面にも出ません（「注文を開く」で注文の画面へ）
- 店の人はレビューを足せません（書くのはお客さんだけ）
- 消したレビューと同じご注文の同じ商品には、お客さんはもう書けません
- 使うのをやめると、管理画面にもショップにも出なくなります（書かれたレビューは残ります）

## 作り

| ファイル | 役 |
|---|---|
| `database/migrations/…_create_reviews_table.php` | 店の DB の表 `reviews`（注文・商品・星・題・本文・表示名・状態・返信）。1 つの注文の 1 つの商品に 1 つ・星・長さ・状態の言葉は DB でも守る。名前・メール・届け先は持たない |
| `src/ReviewableOrders.php` | 書ける注文（ショップの物販の注文で発送済みか完了）と、その商品・会員の注文か |
| `src/ReviewInput.php` | お客さんの欄の確かめ（長さ・制御文字と向きの印・幅の無い空白・表示名の `@`） |
| `src/Reviews.php` | 書く・公開する・非公開にする・消す・返信する。連鎖のロック → 行のロック → イベント（中身は ID・星・状態だけで、文は入れない） |
| `src/ReviewLinks.php` | レビューの画面の道筋（ゲストには署名・24 時間の期限・店の ID つき） |
| `src/Http/ReviewController.php` | ショップの画面（マイページのレビュー・注文のレビュー・書く欄）。接続元ごとに 1 時間 10 回まで |
| `src/ReviewAdminPage.php` | 管理画面の App の画面（一覧・1 件・操作）と、直すだけの欄（店からの返信。核の `AdminPageHandler` と `AdminFormHandler`） |
| `src/ReviewProductPanel.php` | ショップの商品の画面の並び（核の `ProductPanelProvider`。平均の星と件数。描くのは核の部品） |
| `src/ReviewOrderLink.php` | ご注文の確認とマイページの注文の履歴の「レビューを書く」（核のご注文の画面のリンクの口 `OrderLinkProvider`） |
| `resources/views/` | ショップの App の画面（テーマの外枠の中に描く。App のタグは差し込まない） |

テストは `tests/Feature/Plugin/ReviewsAppTest.php`（ゲストと会員の書き方・発送の前や買っていない人は書けない・1 つに 1 つ・公開の前は出ない・平均と件数・エスケープ・文の決まり・回数の上限・店の境界・権限・使わない店・4 つのテーマ）。
