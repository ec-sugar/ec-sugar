# Pinterest タグ（App）

Pinterest の広告から来たお客さんが、ショップのページを見たことと、購入したことを Pinterest に知らせます。広告の効果を確かめたり、広告の配信を良くしたりするのに使います。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押す。一覧の「Pinterest タグ」の名前（か右の「設定」）を押すと、この App の画面に入る
2. 「設定」の「タグ ID」に入れて、「設定を保存する」を押す
   - タグ ID は、Pinterest の広告マネージャの「コンバージョン」で、タグの名前の横に出る 9〜16 桁ほどの数字です
   - 数字のほかの文字（スニペットのコードなど）は入れられません。コードを貼る必要はありません
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
3. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
4. Pinterest の広告マネージャのタグの設定で、**「自動拡張マッチ（Automatic enhanced match）」を切ってください**。入れておくと、ページの入力欄からメールなどを Pinterest が自分で拾おうとします（このショップでは入力欄のある画面にタグを入れませんが、念のため）

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で「ページの表示（page）」を送ります
- ご注文を受け付けた画面で「購入（checkout）」を送ります。同じ画面を読み直しても、同じタブでは二度送りません
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、ブラウザと端末の情報、Pinterest の Cookie の識別子
- 購入のとき: 注文の番号、合計の金額、通貨、品の ID と数
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所（照合用の情報〔拡張マッチ〕は使いません）

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。

## 知っておくこと

- 金額は日本円のまま送ります。Pinterest の開発者向けの資料は使える通貨に日本円を挙げていないため、広告マネージャで購入の金額が日本円で見えるかを、最初の注文のあとに確かめてください
