# お気に入り（EC-SUGAR の App）

会員のお客さんが、商品の画面と一覧のハートを押してお気に入りに入れ、マイページで見返せる App です。お気に入りの商品が値下げ・再入荷したら、選んだお客さんへ 1 日 1 通にまとめてメールで知らせます。
核の口（プラグインの表・商品の画面の買い方の口・一覧の札の口・マイページの入口・App の画面・お知らせのメールの同意）だけで作っています（ADR 0025・0050・0051・0067・0071）。

## 使い方

1. 管理画面の店のメニュー「App」から「お気に入り」を開き、「使う」にします。
2. ショップの商品の画面（「カートに入れる」の下。売り切れの商品にも）と、一覧・トップの商品の写真の右上にハートが出ます。
   - **会員**: 押すとお気に入りに入り、もう一度押すと外れます（JavaScript があれば画面を移らず、無ければ元の画面へ戻ります）。1 人 500 件まで
   - **ゲスト**: 押すとログインの画面へ。ログインすると、押した商品がお気に入りに入って商品の画面へ戻ります
3. マイページの「お気に入り」で一覧を見られます。ショップに出すのをやめた商品は名前だけが残り、外せます。
4. 同じ画面で「値下げしたらお知らせを受け取る」「売り切れから再入荷したらお知らせを受け取る」を選べます（はじめはどちらも選んでいません）。
5. 管理画面のメニュー「App」の下の「お気に入り」で、お気に入りの多い商品の順位を見られます。**誰が入れたかは出しません**（数だけ）。

## 値下げ・再入荷のお知らせ（宣伝のメールです）

- 毎日 10:15（日本時間）の `favorites:notify` が、前の日と比べて値段の下がった商品（種類のいちばん安い値段、税込み）と、売り切れから買えるようになった商品を見つけ、選んだお客さんへ 1 通にまとめて送ります（1 日 1 通まで）
- 宣伝のメール（特定電子メール）にあたるので、**ショップのお知らせのメールに登録し、登録を確定したお客さんにだけ**送ります。同意は App「メルマガ・一斉メール」が持っているので、知らせを使うならメルマガの App も使ってください（使っていない店では誰にも送りません）
- メールの終わりに、送り主の名前・住所・問い合わせ先（店の設定の「特定商取引法に基づく表記」から）と、配信の停止のリンクを載せます。表記が足りない店では送りません。メールのソフトのワンクリックの停止（RFC 8058）にも応えます。止めると、その人のお気に入りの知らせ（値下げ・再入荷とも）が止まります
- App「再入荷のお知らせ」で同じ商品の入荷を待っている（か、3 日のうちに知らされた）お客さんには、こちらから再入荷を知らせません（2 通にしないため）

## 守り

| こと | どうしているか |
|---|---|
| 他人のお気に入りを変える・見る | 会員の印は台帳の ID で持ち、どの操作もログインしている自分の分だけ |
| 出ていない商品・ほかの店の商品 | ショップに出ている商品だけを足せる（この店の DB だけを読む） |
| 外のサイトから押させる | ハートは POST と CSRF の合い言葉。押した後の形を送るので、2 回押しても同じ |
| 戻り先で外へ飛ばす | 戻る先は自分のショップの道筋だけ。ログインの戻り先は核の決まり（App の `/p/…` だけ）。ログインの後に足すのは、その前に頼んだ商品だけ |
| 大量に作る | 1 人 500 件（会員ごとの錠の中で数える）、接続元ごとに 1 分 60 回 |
| 平文の個人情報 | 表・記録・キューにはメールを置かない（送る時に会員の台帳の暗号化された値から読む） |
| ショップの重さ | 札が何枚あっても、会員の印は 1 回の要求で 1 度だけ読む（ゲストは読まない） |
