# 贈り物（EC-SUGAR の App）

お届け先の住所を知らなくても、贈り物として買える App です。お支払いの後に「受け取りのリンク」ができ、買った方がそのリンクをメールや LINE で贈りたい方へ送ります。リンクを開いた方がお届け先を入れると、お店が発送します。受け取る方には値段を見せず、メッセージを添えられます（ADR 0055）。

## 使い方（お店の人）

1. 管理画面の店のメニュー「App」から「贈り物」を開き、「使う」にします。
2. 必要なら、App の設定で「受け取りの期限（日）」を入れます（1〜60。空なら 14 日）。期限は、お支払いが完了した時から数えます。
3. ショップのご注文の手続きの画面に「贈り物として送る（お届け先は受け取る方が入力します）」が出ます。

- 送料は、買う時に選べるお届け先の中でいちばん高い送料をいただき、受け取る人が住所を入れた時に、その都道府県の送料との差額を自動で返金します（ADR 0064）。Stripe が返金を断ったときは、お店の人が注文の画面の「差額をもう一度返金する」で返金し直します。受け取りの住所は、郵便番号と都道府県が合わないと受け付けません
- お相手がお届け先を入れるまで、その注文は発送できません（注文の画面の発送の欄に出ません。注文の画面の上に「贈り物・受け取り待ち（期限 ◯）」）
- 期限の 3 日前に、買った方へ「期限が近づいています」のメールを送ります。期限を過ぎてもお届け先が入らない贈り物は、1 時間ごとの定期チェック（`gifts:run`）で取り消して全額を返金し、在庫を戻します
- メニューの「App」の下の「贈り物」に、受け取り待ち・受け取り済み・返金できなかった・取り消しの一覧が出ます（差出人・メッセージ・お届け先は出しません）
- お店が取り消す（全額を返金する）ときは、注文の画面の「注文を取り消す」です（「お金」の権限と、パスキーでの再確認）。App の画面には返金の操作を置いていません
- 返金ができなかった贈り物は「返金できなかった」にして、自動では返金し直しません。ホームの「やること」に出ます。注文の画面の「返金の記録」を確認し、もう一度「注文を取り消す」を押すと、同じ返金の続きから進みます
- 使うのをやめると、新しい贈り物の注文は受けません。受け取りの画面と買う人の画面も開かなくなります。**受け取り待ちの贈り物の期限の処理（3 日前の知らせと期限での自動の返金）は続けます**（お金を宙に浮かせないため。知らせには開かないリンクを載せません）

## 使い方（買う方）

1. ご注文の手続きの画面で「贈り物として送る」を選び、差出人のお名前（空ならご依頼主のお名前）とメッセージ（任意、500 文字まで）を入れます。お届け先は入れません。
2. お支払いの後、ご注文の知らせのメールに「受け取りのリンク」と「LINE で送る」が届きます。注文を受け付けた画面の「受け取りのリンクを開く」からも、リンクをコピーできます。
3. リンクを送り間違えたときは「リンクを作り直す」で前のリンクを使えなくできます（メールの「リンクを作り直す・取り消す」・ご注文の状況の「贈り物のリンク・取り消し」・会員はマイページの「贈り物」から）。
4. お相手が受け取る前なら「取り消して返金する」で取り消せます（全額を返金します）。
5. お相手がお届け先を入れると「贈り物が受け取られました」のメールが届きます（お届け先は載せません）。期限の 3 日前と、期限で返金した時にもメールが届きます。

## 使い方（受け取る方）

1. 届いたリンクを開くと、差出人のお名前・メッセージ・品物（名前・写真・数）が出ます（値段は出ません）。
2. お名前・郵便番号（入れると住所が入ります）・住所・電話番号を入れ、「入力の確認へ」→「このお届け先で受け取る」。
3. 確定の後は、同じリンクで「受け付けました」「発送しました（お問い合わせ番号）」が見られます。お届け先は直せません（お店へお問い合わせください）。

## 作り

| ファイル | 役 |
|---|---|
| `database/migrations/…_create_gift_orders_table.php` | 店の DB の表 `gift_orders`（注文ごとに 1 行。差出人とメッセージ・token は店の鍵で暗号化、token の sha256 で引く。状態と形は DB の制約でも守る） |
| `src/GiftCheckout.php` | 核の口 `GiftHandler` の実装（注文の確定の中で差出人とメッセージを置く・払いが確かになったらリンクを作る・買う人に見せる様子） |
| `src/GiftOrders.php` | 置く・リンクを作る・作り直す・受け取る。連鎖のロック → 贈り物の行のロック → イベント（`gift.placed`・`gift.link_created`・`gift.link_renewed`・`gift.claimed`。中身は ID だけ） |
| `src/GiftStatus.php` | 見せる状態と言葉（注文の画面で取り消した・発送したを重ねる） |
| `src/Http/GiftReceiveController.php` | 受け取る人の画面 `/p/gift/{token}`（入れる → 確かめる → 確定。回数の上限・no-referrer・noindex） |
| `src/Http/GiftOrderController.php` | 買う人の画面 `/p/gift/orders/{注文}`（リンク・写す・LINE・作り直す・取り消す）とマイページの `/p/gift/account` |
| `src/GiftCancellation.php` | 取り消して全額を返金する（買う人の取り消しと期限）。① ロックの中で「取り消しの途中」に ② ロックの外で核の注文の取消（`SaleOrderService::cancel`）③ 答えを書く。返金できなければ「止めた」にして、もう自動では返金しない |
| `src/GiftRounds.php`・`src/Console/RunGiftsCommand.php` | 毎時の `gifts:run`（使う店だけ）: リンクの作り直し（払いの確定の時に作れなかった分）・注文の画面で取り消した贈り物を合わせる・期限の 3 日前の知らせ・期限を過ぎた贈り物の取り消し・途中で止まった取り消しを止める |
| `src/SendGiftMail.php`・`src/Mail/GiftMail.php` | 買う人への知らせ（受け取られた・期限の 3 日前・期限で返金した・取り消した）。キューに載せるのは ID と種類だけ |
| `src/GiftOrderLink.php` | ご注文の画面（ご注文の確認・マイページの注文の履歴）の「贈り物のリンク・取り消し」（核の App のご注文のリンクの口 `OrderLinkProvider`。行き先は署名つき） |
| `src/GiftAdminPage.php` | 管理画面の App の画面（一覧と 1 件。ホームの「やること」に返金が止まった贈り物） |

核の側（ADR 0055 の 1）: お届け先の入力を待つ受渡（`Fulfillment::awaitingAddress()`・`FulfillmentService::setAddress()`）、贈り物の口（`App\Core\Plugin\Contracts\GiftHandler`、`App\Core\Order\Gifts`）、注文の入力の印（`CheckoutInput::$gift`）、テーマに置く核の部品（`gift-fields`・`gift-summary`・`gift-share`。docs/design/theme-api.md の「贈り物」）。

テストは `tests/Feature/Plugin/GiftAppTest.php`（使わない店では選べない・お届け先なしで注文になり発送できない・値段と買う人の個人情報を出さない・お届け先は 1 回だけ・作り直しで前のリンクが無効・ほかの店のリンク・取り消しの途中は受け取れない・エスケープ・回数の上限・0 円の注文）、`tests/Feature/Plugin/GiftExpiryTest.php`（期限の 3 日前の知らせは 1 回・期限で返金は 1 回・同時に 2 つ走っても 1 回・返金の失敗で止めて頼み直さない・買う人の取り消しは受け取られる前だけ・管理画面の表示と発送）と `tests/Feature/Core/GiftFulfillmentTest.php`（核の受渡）。
