# カゴ落ちのお知らせ（EC-SUGAR の App）

注文の手続きを始めたのに、お支払いの前で終わったお客さんへ、商品をカートに戻せるリンクをメールで 1 回お送りする App です。
**お知らせのメールに登録し、登録を確定したお客さんだけ**に送ります（同意は App「メルマガ・一斉メール」が持ち、核の口 `MarketingConsent` で聞きます）。
核の口（プラグインの表・App の画面・App の設定・同意の口）だけで作っています（ADR 0025・0051・0067）。

## 使い方

1. 管理画面の店のメニュー「App」から「メルマガ・一斉メール」と「カゴ落ちのお知らせ」を開き、どちらも「使う」にします。メルマガの App を使っていないと、誰にも送りません
2. 設定の「特定商取引法に基づく表記」に「販売業者」「所在地」「電話番号かメールアドレス」を書きます（送り主の表示。足りないと送らず、ホームの「やること」に出ます）
3. App の設定で「お知らせを送るまで待つ時間」（1〜72 時間。既定 3 時間）と「メールの書き出しの一文」（空なら既定の文）を選びます
4. 毎時の `cart-reminders:run` が、払われずに消えた注文を拾い、1 通ずつ送ります
5. 管理画面のメニュー「App」の下の「カゴ落ちのお知らせ」で、直近 30 日の送った数・リンクから戻った数・払われた数・送らなかった数（理由つき）を見られます。**宛先のメールアドレスは出しません**（注文番号と日時だけ）

## 送る注文と送らない時

- 対象: ショップで確定した物販の注文で、1 円以上・払われずに取り消されたもの（支払いの期限切れ・払う前の取消）
- 送らない: コンビニ払いの入金待ちになった注文（期限切れの知らせが別にある）・同じメールで後から注文がある・同じメールへ 7 日のうちに送った・商品が今は 1 つも買えない・送り主の表示が足りない・同意していない・App を使うのをやめた・App を使い始める前に消えた・待つ時間と 24 時間より前に消えた
- 同時に処理が走っても 1 つの注文に 1 通（注文ごとに一意の記録）。送れなかったメールは送り直しません（2 通にしないため）

## メールの中身

- 商品の今の名前と写真（今ショップで買えるものだけ）と「カートに戻す」のリンク。**値段・数・注文番号・名前・住所は載せません**
- 終わりに、受け取ると選んだ方へ送っていること・配信の停止のリンク・送り主の名前・住所・問い合わせ先（特定電子メール法 第 4 条）。ヘッダーにワンクリックの配信停止（`List-Unsubscribe`・`List-Unsubscribe-Post`。RFC 8058）
- 配信の停止は、お知らせのメールの受け取りの同意そのものを止めます（メルマガも届かなくなります）。準備中のショップでも受けます

## 「カートに戻す」のリンク

- 7 日のうち使えます。開くと、今の値段と在庫でカートを作り直してカートの画面へ移ります（ブラウザにカートがあれば足します。2 回開いても数は増えません）
- 売り切れ・非公開・販売を終えた商品は外し、名前を一言で出します。名入れなどのオプションは戻さず、もう一度選んでもらいます
- 合い言葉は 32 バイトの乱数で、表にはハッシュだけ。その店でだけ使えます。接続元ごとに 1 時間 30 回まで

## 守り

| こと | どうしているか |
|---|---|
| 同意の無い人へ送らない | 送る直前に、メルマガの App に「受け取りを確かめた人か」を聞く。App が無い・使っていない・落ちた時は送らない |
| 同じ人へ何通も送らない | 注文ごとに一意の記録、送る仕事は queued の行だけを行のロックで取る。同じメールは 7 日に 1 通（メールの索引ごとのロックの中で確かめる） |
| 平文の個人情報を残さない | 表・キュー・イベントにメールを置かない（送る時に注文の買う人の暗号化された値から読む）。失敗の記録は例外の種類だけ |
| 他人のリンクを使わせない | 合い言葉はハッシュで引く・その店の DB だけ・7 日で切れる・総当たりは回数で止める。入るのはその注文の商品だけ |
| 管理画面で宛先を見せない | 一覧と 1 件は注文番号・状態・日時・数だけ |
