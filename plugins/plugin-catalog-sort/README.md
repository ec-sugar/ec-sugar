# 並び順と絞り込み（EC-SUGAR の App）

ショップの商品一覧の並びをお店で決め（おすすめ順）、お客さんが価格・タグ・在庫ありで絞り込めるようにする App です。
核の口（`CatalogBrowseHandler`）に並びと絞り込みを渡すだけで、一覧を読むのも描くのも核とテーマのままです（この App はショップの経路を持ちません）。

## 使い方

1. 管理画面の店のメニュー「App」から「並び順と絞り込み」を開き、「使う」にします（運用の段階・直前の再確認）。
2. メニューの「App」の下に「並び順と絞り込み」が出ます。右上の「商品を追加」で商品を選ぶと、一覧のいちばん後ろに入ります。
3. 1 件の画面の「上へ」「下へ」で並びを動かし、「直す」の欄でタグを書きます（カンマ区切りで 5 個まで、1 つ 24 文字まで）。「一覧から外す」で並びとタグを消します（商品は消えません）。
4. App の「設定」で、ショップに出すものを選びます。

| 設定 | すること |
|---|---|
| 最初から「おすすめ順」で並べる | お店で決めた並びを、商品一覧の最初の並びにします（切ると、お客さんが「おすすめ順」を選んだ時だけ） |
| 価格で絞り込めるようにする | 「¥1,000 未満」などの帯を出します |
| 価格帯の区切り（円） | 半角の数字とカンマで 5 つまで（例 `1000,3000,5000,10000`）。空なら 1,000・3,000・5,000・10,000 円 |
| タグで絞り込めるようにする | この画面で商品に付けたタグを出します（付けた商品の多い順に 20 個まで） |
| 「在庫あり」で絞り込めるようにする | 売り切れの商品を隠せるようにします |

- 並びを決められるのは **500 点まで**（それより後ろの商品は、おすすめ順でも新着順で続きます）
- 使うのをやめると、ショップの並べ替えと絞り込みは今までどおり（新着順・価格の順）に戻ります。決めた並びとタグは残るので、また使うにすれば戻ります
- 止めた店では、オーナーが App の画面から「この App のデータを消す」で並びとタグを消せます（ADR 0092）
- 予約販売の商品は在庫を使わないため、「在庫あり」では在庫のある商品だけが出ます（在庫を使わない扱いの商品〔ダウンロード・役務・予約の品〕は、札と同じく「在庫あり」として残ります）

## 作り

| ファイル | 役 |
|---|---|
| `composer.json` | パッケージとマニフェスト（`extra.ec-sugar`: 名前・プラグイン API・目的 `products`・設定の宣言） |
| `src/CatalogSortServiceProvider.php` | 登録簿への登録（`PluginDefinition`。管理画面の画面・核の並びと絞り込みの口・データを消す口） |
| `database/migrations/…_create_catalog_sort_items_table.php` | 店の DB の表 `catalog_sort_items`（商品ごとに 1 行・並びは一意・タグは jsonb の配列で GIN の索引） |
| `src/CatalogSortItems.php` | 足す・直す・入れ替える・外す。連鎖のロック → 行のロック → 同じトランザクションのイベント（`catalog_sort.created`・`updated`・`moved`・`removed`。中身は商品の ID とタグの数だけ） |
| `src/CatalogSortAdminPage.php` | 管理画面の App の画面（一覧・1 件・上へ・下へ・外す）と足す・直すの欄 |
| `src/CatalogSortBrowse.php` | 核の口 `CatalogBrowseHandler`（並び・価格の帯・タグ・在庫ありと、タグの商品） |
| `src/CatalogSortSettings.php` | 設定の読み出し（範囲の外の値は捨てる） |
| `src/CatalogSortDataPurger.php` | 止めた店でデータを消す口（ADR 0092） |

守りの要点:

- 絞り込みの入力（`price`・`tag`・`stock`）は、核（`CatalogFilters`）が App が返した選択肢と同じ文字の時だけ受け、違えば「選んでいない」と同じに扱います。**列の名前や SQL を入力から作りません**
- タグの URL に出るのは、タグの名前から作る短い印（`t` ＋ SHA-256 の先頭 10 文字）です。日本語をそのまま URL に出さず、核の選択肢の形に収まります
- タグの文は保存の時に長さ・数・使える文字を確かめ、`< > " ' \` \\` と制御文字は断ります（ショップでは Blade が `{{ }}` で出します）
- 読むのはテナント（店）の DB だけ。ほかの店の商品は、店の文脈では見つかりません

テストは `tests/Feature/Plugin/CatalogSortAppTest.php`、管理画面のヘルプは `resources/admin/help/catalog-sort.js` です。
