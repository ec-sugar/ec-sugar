# 動画（App）

ページに YouTube・Vimeo の動画を置けます。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押します。一覧の「動画」の名前（か右の「設定」）を押すと、この App の画面に入ります
2. 上の「この店では」の「使う」を押します（設定の項目はありません）
   - 切り替えは「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
3. メニューの「デザイン」から、トップ（「テーマ」の「プレビューを見ながらトップページを編集する」）か自由なページ（「ページ」）の編集の画面を開き、「＋ 区画を足す」の「動画（App「動画」）」から「横いっぱい」か「文の幅」を選びます
4. 右の欄の「動画の URL」に、YouTube か Vimeo の動画のページの URL を貼ります。見出し・動画の説明は任意です
5. 必要なら、再生の仕方を選びます（選ばなければ、どれも「しない」「出す」）
   - **自動で再生する**: ページを開くと再生を始めます。ブラウザは音ありの自動再生を止めるので、**自動でミュートになります**
   - **音を消す（ミュート）**: 最初から音を消して始めます（お客さんは操作の表示から音を出せます）
   - **操作の表示（再生バーなど）**: 「出さない」にすると、再生バーや音の大きさのボタンが消えます。**Vimeo は有料のプランの動画でだけ効きます**
   - **繰り返す（ループ）**: 終わったら最初から再生し直します
   - 自動で再生して操作の表示も出さないと、お客さんが動画を止められないことがあります（見る人の負担になり、アクセシビリティの決まり WCAG の 2.2.2 にも触れます）。操作の表示は出したままにするか、5 秒より短い動画にしてください
6. 「公開する」を押すと、ショップに出ます

貼れる URL の形（https だけ）:

- YouTube: `https://www.youtube.com/watch?v=…`・`https://youtu.be/…`・`https://www.youtube.com/shorts/…`・`https://www.youtube.com/live/…`・`https://www.youtube.com/embed/…`
- Vimeo: `https://vimeo.com/123456789`（限定公開は `https://vimeo.com/123456789/abc123def`）・`https://player.vimeo.com/video/123456789`

ほかの形（チャンネルや再生リストのページ、ほかのサイト）は「URL の形が違います」と断ります。

## お客さんにはどう見えるか

- ページを開いた時から動画の枠が出ます（同意の帯で聞くことはありません。JavaScript が無いブラウザでも出ます）。「自動で再生する」を選ばなければ、お客さんが再生を押すまで再生しません
- 動画の下の「別のタブで開く」のリンクで、動画のサイトで見ることもできます

## 何が送られるか

動画の区画のあるページを表示したときに、Google LLC（YouTube）か Vimeo.com, Inc. へ送られます。

- IP アドレス、端末とブラウザの情報、ショップのアドレス（ドメインまで。ページの道筋は送りません）、見た動画と再生の状況
- YouTube はプライバシー強化モード（`youtube-nocookie.com`）、Vimeo は追跡しない設定（`dnt=1`）で埋め込みます

注文の入力・確認、ご注文の状況の画面には動画の区画を置けません。送る内容は、ショップの「外部送信に関する公表」のページに自動で載ります。
