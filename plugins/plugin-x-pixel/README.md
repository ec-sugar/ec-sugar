# X ピクセル（App）

X（旧 Twitter）の広告から来たお客さんが、ショップのページを見たことと、購入したことを X に知らせます。広告の効果を確かめるのに使います。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押す。一覧の「X ピクセル」の名前（か右の「設定」）を押すと、この App の画面に入る
2. 「設定」の「ピクセル ID」に入れる
   - ピクセル ID は、X の広告マネージャーの「イベントマネージャー」で見られる英小文字と数字の ID です（例: `oka17`）。ベースコードの `twq('config', 'oka17')` の中の文字です
   - コードは貼れません。コードを貼る必要はありません（タグはショップが入れます）
3. 購入を数えるときは、イベントマネージャーで購入のイベントを作り、同じ「設定」の「購入のイベント ID」にも入れる
   - イベントのコードが `tw-oka17-ol288` なら、最後の `ol288` を入れます
   - 空のままなら、ページの表示だけを送ります
4. 「設定を保存する」を押す
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
5. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で、ページの表示を送ります
- ご注文を受け付けた画面で購入を送ります。同じ画面を読み直しても、同じタブでは二度送りません
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、ブラウザと端末の情報、X の Cookie の識別子、ページを見ていた時間
- 購入のとき: 注文の番号、合計の金額、通貨、品の ID と数
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所（照合用の情報は使いません）

X のタグには、ページの入力欄からメールアドレスや電話番号を自分で拾う機能（自動の照合）があります。この App は「データの使い方の制限」（restricted_data_use）を付けて送るので、この機能は動きません。その代わり、X は送った情報を広告の配信の最適化には使わず、効果の測定に使います。

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。
