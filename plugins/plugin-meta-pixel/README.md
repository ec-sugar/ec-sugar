# Meta ピクセル（App）

Facebook・Instagram の広告から来たお客さんが、ショップのページを見たことと、購入したことを Meta に知らせます。広告の効果を確かめたり、広告の配信を良くしたりするのに使います。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押す。一覧の「Meta ピクセル」の名前（か右の「設定」）を押すと、この App の画面に入る
2. 「設定」の「ピクセル ID」に入れて、「設定を保存する」を押す
   - ピクセル ID は、Meta の「イベントマネージャ」で、データソースのピクセルを選ぶと名前の下に出る 10〜20 桁ほどの数字です
   - 数字のほかの文字（スニペットのコードなど）は入れられません。コードを貼る必要はありません
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
3. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
4. Meta のイベントマネージャのピクセルの設定で、**「自動詳細マッチング」を切ってください**。入れておくと、ページの入力欄からメールなどを Meta が自分で拾おうとします（このショップでは入力欄のある画面にタグを入れませんが、念のため）

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で「ページの表示（PageView）」を送ります
- ご注文を受け付けた画面で「購入（Purchase）」を送ります。同じ画面を読み直しても、同じタブでは二度送りません
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、ブラウザと端末の情報、Meta の Cookie の識別子
- 購入のとき: 注文の番号、合計の金額、通貨、品の ID と数
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所（照合用の情報〔詳細マッチング〕は使いません）

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。
