# Google 広告（App）

Google 広告から来たお客さんの購入を、コンバージョンとして計測します。

## 使い方

1. Google 広告で、購入のコンバージョンアクションを作ります（「目標」→「コンバージョン」→「概要」→「新しいコンバージョンアクション」→ ウェブサイト）
2. そのアクションを開き、「タグを設定する」→「自分でタグを追加する」（Google タグを使う）を選ぶと、イベントのスニペットに `send_to: 'AW-123456789/AbC-D_efG-h12_34-567'` のような行があります
   - `/` の前の `AW-` で始まる部分が **コンバージョン ID**、後ろが **コンバージョンラベル** です
3. EC-SUGAR の管理画面で店を開き、メニューの「App」を押します。一覧の「Google 広告」の名前（か右の「設定」）を押すと、この App の画面に入ります
4. 「設定」の「コンバージョン ID」と「コンバージョンラベル」に 2 つを入れて、「設定を保存する」を押します
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
5. 上の「この店では」の「使う」を押します
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
6. 「使う」にして 2 つが入っていると、ショップで計測が始まります。同意の帯は既定では出しません。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「広告の計測」に同意したときだけ計測します

Google アナリティクス 4 の App と一緒に使えます（Google のスクリプトの読み込みは 1 回にまとめます）。

## 何が送られるか

送信先は Google LLC です。

- 見たページの URL、参照元の URL、端末とブラウザの情報、Cookie の識別子、広告のクリックの識別子
- 購入の完了の画面では、**注文の番号・金額・通貨だけ**（コンバージョン。注文の番号は二重に数えないために使われます）

お客さんの名前・メール・住所・電話は送りません。注文の入力・確認、ご注文の状況、アカウントの画面では、この App は動きません。
送る内容は、ショップの「外部送信に関する公表」のページに自動で載ります。

## お店の人にお願いすること

- **拡張コンバージョン**（メールなどを送る機能）は使いません。Google 広告の設定で有効にしないでください
- Google タグの設定の「ユーザー提供データの自動検出」は切ってください（https://support.google.com/google-ads/answer/14662970）
- リマーケティング（広告のパーソナライズ）には使いません（お客さんへの同意の文が「広告の効果を確かめる」だけのため）
