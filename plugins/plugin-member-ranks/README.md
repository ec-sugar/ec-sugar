# 会員ランク（EC-SUGAR の App）

直近 12 か月のお買い物の額で会員のランク（3 つまで。既定の例はブロンズ・シルバー・ゴールド）を決め、ランクごとの**会員価格**・**ポイントの上乗せ**・**会員だけ・ランクだけの商品**を出す App です。
特典は核の会員の特典の口（`MemberBenefitsHandler`）で渡し、値引きは核の値引きの行（ADR 0054）、いちばん得な 1 つの決まり（ADR 0065）、ポイントの帳簿（ADR 0068）にそのまま載ります（ADR 0025・0050・0051・0079）。

## 使い方

1. 管理画面の店のメニュー「App」から「会員ランク」を開き、「使う」にします
2. App の設定で、使うランクの数（1〜3）と、ランクごとの名前・なる購入額（円）・会員価格（商品の代金の割引 %、0〜50）・ポイントの上乗せ（%、0〜10 を 0.1 きざみ）を決めます。空の項目は例の値です（ブロンズ 10,000 円・割引なし・+0.5% ／ シルバー 50,000 円・3% 引き・+1% ／ ゴールド 100,000 円・5% 引き・+2%）。上のランクほど大きな額にします
3. 会員だけ・ランクだけにしたい商品は、商品の画面の「会員ランク」の欄で見せる相手を選びます
4. 会員はマイページの「会員ランク」で、今のランク・直近 12 か月の額・次のランクまでの額・特典を見られます
5. 管理画面のメニュー「App」の下の「会員ランク」で、ランクごとの人数と会員の一覧を見られます。1 人の画面で、ランクを手動で設定する・購入額による自動の設定に戻すができます（「お金」の権限の人だけ。押す前にパスキーで本人を確かめます）。**名前やメールは出しません**（会員は ID の末尾 8 文字だけで、押すとお客さんの画面へ。お客さんの画面にもランクの名前が出ます）

## ランクの決め方

- 額は、直近 12 か月（日本の暦の今日の 0 時から 12 か月前より後）に**発送した**ご注文の、受け取ったお金 − 返金（台帳から）。返金はいつ返しても引きます。ギフトカードで払った分は数え、ギフトカードを売ったご注文と、Stripe のテストのモードで払われたご注文は数えません
- 毎日 03:40 の `member-ranks:run` が決め直します。上がった会員には、新しいランクと特典をメールで知らせます（設定で止められます）。下がった時は知らせません。App を使い始めた夜の最初の決め直しは知らせず、ほかの夜も店ごとに 1 分に 60 通ずつ送ります
- 手で決めたランクは、決めた日から 1 年は毎日の決め直しで変えません
- 退会・止めた・まとめた会員は、すぐに特典が無くなり、次の決め直しで「ランクなし」になります

## 特典

- **会員価格**: 商品の代金からランクの % を引く値引き（送料は引かない）。自動の割引・クーポンと重ねず、お支払いの合計がいちばん下がる 1 つだけが効きます（同じなら会員価格）。注文の値引きの行の名前は「ゴールドの会員価格（5% 引き）」
- **ポイントの上乗せ**: 店のポイントの率に足します（店の率と合わせて 20% まで）。ポイントを使わない店では効きません
- **会員だけ・ランクだけの商品**: 見せない人には一覧・検索・商品の画面・写真・カートに出ず、URL を開いても見つからず、注文もできません（カートを通さない定期便・チケット・予約の申し込みも断ります）。商品フィードとサイトマップには載せません
- App を止めると、会員価格とポイントの上乗せは効かなくなり、会員だけ・ランクだけの商品は**誰にも見えなく**なります

## 守り

| こと | どうしているか |
|---|---|
| 値段とポイントを書き換えさせない | 額・率はサーバーが決め、注文の確定の錠の中でカートを読み直す。確かめの画面の指紋（会員価格の印・名前・額・付くポイント）が違えば確定しない |
| 値引きを重ねさせない | 会員価格は値引きの候補の 1 つ。1 つの注文にいちばん得な 1 つ（ADR 0065） |
| 会員だけの商品を URL で買わせない | 核のショップの窓口（`Catalog::published`）が見る人のランクで除く。カート・注文の確定・1 品の注文も同じ答え |
| 会員が開いた答えを外に出さない | フィードとサイトマップはいつもゲストとして読む。見せない商品の写真は、見てよい会員に描いた画面の署名（店・商品・期限）が合う時だけ返し、共有のキャッシュに置かない |
| 店の内側の処理で取りこぼさない | 在庫の知らせ・入荷の見方・管理画面の「ショップで見る」は見る人を問わずに読み、お客さんへ送る再入荷・カゴ落ちのメールは相手ごとに確かめる |
| 手の上げ下げを勝手にさせない | お金の段階・直前の再確認（核が確かめる）。actor をイベントに残す |
| 2 度変えない | どの書き込みも連鎖のロックの中で今のランクと手で決めた印を読み直す。知らせは記録ごとに 1 回（1 文の条件つきの更新） |
| 個人情報を残さない | 表・イベントは台帳の ID・ランクの位置・理由だけ（額は台帳から毎回数える）。知らせの仕事には記録の ID だけを載せ、宛先は送る時に読む |

## 表

- `member_ranks_members`: 会員ごとの今のランク・なった日時・手で決めたランクの期限
- `member_ranks_changes`: ランクの動き（追記だけ。上がった知らせの印だけを後から書く）
- `member_ranks_listings`: 会員だけ（0）・ランクだけ（1〜3 以上）の商品（1,000 点まで）
