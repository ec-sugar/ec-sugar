# よくある質問（EC-SUGAR の App）

ショップの商品の画面の説明の下に、よくある質問と答えを出す App です。全部の商品に出す質問（共通）と、商品ごとの質問を書けます。
EC-SUGAR の最初の見本のプラグインで、核の口（プラグインの表・App の画面・商品の画面の差し込み口）だけで作っています（ADR 0025・0050・0051）。

## 使い方

1. 管理画面の店のメニュー「App」から「よくある質問」を開き、「使う」にします（運用の段階・直前の再確認）。
2. メニューの「App」の下に「よくある質問」が出ます。右上の「質問を追加」から、質問・答え・表示する商品（「すべての商品（共通）」か 1 つの商品）・ショップに表示するかを入れて「追加」。
3. 一覧の質問を押すと 1 件の画面です。「直す」の欄で書き直す、「上へ」「下へ」で並びを入れ替える、「削除する」で消す（取り消せないので、パスキーでもう一度確認します）。
4. ショップの商品の画面の説明の下に「よくある質問」が出ます。質問を押すと答えが開きます（`<details>`。JavaScript は使いません）。

- 答えの改行はそのまま出ます。HTML は使えません（書いても文字のまま出ます）
- 1 つの店に 200 個まで。1 つの商品の画面に出るのは、公開した質問のうち全部の商品のものとその商品のもの、並びの順に 50 個まで
- 「ショップに表示する」をオフにすると、削除せずに隠せます
- 使うのをやめると、管理画面にもショップにも出なくなります（書いた質問は残ります）。やめた後は、オーナーが App の画面の「この App のデータを消す」で質問を全部消せます（元に戻せません。ADR 0092。`src/FaqDataPurger.php` がデータを消す口のいちばん小さい見本）
- 商品の選択肢は、名前の順に先頭の 499 個までです（それより多い店では、選べない商品があります）

## 作り

| ファイル | 役 |
|---|---|
| `database/migrations/…_create_faq_items_table.php` | 店の DB の表 `faq_items`（質問・答え・商品〔空は全部の商品〕・並び・公開か）。長さと空でないこと、並びの一意は DB でも守る |
| `src/FaqItems.php` | 足す・直す・並べ替える・消す。連鎖のロック → 行のロック → イベント（`faq.created`・`faq.updated`・`faq.moved`・`faq.deleted`。中身は ID と真偽・変えた欄の名前だけで、文は入れない） |
| `src/FaqAdminPage.php` | 管理画面の App の画面（一覧・1 件・操作）と、足す・直すの欄（核の `AdminPageHandler` と `AdminFormHandler`） |
| `src/FaqProductPanel.php` | ショップの商品の画面の並び（核の `ProductPanelProvider`。描くのは核の部品） |

テストは `tests/Feature/Plugin/FaqAppTest.php`（使わない店では出ない・店の境界・公開していない質問・エスケープ・並べ替え・消す・4 つのテーマ）。
