# 地図（Google マップ）（App）

住所か場所の名前を入れると、ページに Google マップの地図を置けます。API キーなどの設定は要りません。

## 使い方

1. 管理画面で店を開き、メニューの「App」を押します。一覧の「地図（Google マップ）」の「この店では」の「使う」を押します
   - 切り替えは「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
2. メニューの「デザイン」から、トップ（「テーマ」の「プレビューを見ながらトップページを編集する」）か自由なページ（「ページ」）の編集の画面を開き、「＋ 区画を足す」の「地図（App「地図（Google マップ）」）」から「横いっぱい」か「地図と案内」を選びます
3. 右の欄の「場所」に、住所か場所の名前を文字で入れます（例: `東京都千代田区丸の内1-9-1`、`東京駅`）。地図の URL（`https://maps.app.goo.gl/…` など）は入れられません。見出しと案内の文（住所・行き方・営業時間など）は任意です
4. 「公開する」を押すと、ショップに出ます。場所が空の間は、ショップには出ません（編集の画面では「欄を入れるとここに出ます」）

## お客さんにはどう見えるか

- ページを開いた時から地図が出ます（同意の帯で聞くことはありません。JavaScript が無いブラウザでも出ます）
- 地図の下の「別のタブで開く」のリンクで、Google マップで場所を開くこともできます

## 何が送られるか

地図の区画のあるページを表示したときに、Google LLC へ送られます。

- IP アドレス、端末とブラウザの情報（Google の Cookie があればそれも）、ショップのアドレス（ドメインまで）、地図に入れた場所の文字と地図の操作

注文の入力・確認、ご注文の状況の画面には地図の区画を置けません。送る内容は、ショップの「外部送信に関する公表」のページに自動で載ります。

## 知っておくこと（キーの要らない埋め込みの危うさ）

- 地図は `https://www.google.com/maps?q=場所&output=embed` の形で埋め込みます。**この形は Google の公式の資料にありません**。Google が予告なく止めたり形を変えたりすると、この App を使うすべての店で地図が出なくなります（ページのほかの部分はそのまま出ます）
- そうなったら、公式の **Maps Embed API**（API キーが要る。`https://www.google.com/maps/embed/v1/place?key=…&q=…`）へ戻します。戻す手順は ADR 0040 の 6 にあります。戻すと、店ごとに Google Cloud で API キーを作って入れてもらう手間が増えます

## 公式の資料

- Maps URLs（外で開くリンク）: https://developers.google.com/maps/documentation/urls/get-started
- 戻すときの Maps Embed API: https://developers.google.com/maps/documentation/embed/get-started

作りの決まりと、キーの要らない埋め込みにした理由は ADR 0040 の 6 と docs/design/app-sections.md。
