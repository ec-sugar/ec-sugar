# 友だち紹介（EC-SUGAR の App）

会員ごとの紹介のリンクから来た方が会員になり、**最初のご注文が発送されたら**、紹介した方と紹介された方の両方にポイントを付ける App です。
ポイントは核のポイントの帳簿（ADR 0068）に、核の口 `PointService::grant`（理由 `referral`）で付けます。
核の口（プラグインの表・App の画面・App の設定・マイページの入口・核の知らせ）だけで作っています（ADR 0025・0051・0075）。

## 使い方

1. 設定の「ポイント」を「使う」にします（使わない店では働きません。App の画面のホームのやることにも出ます）
2. 管理画面の店のメニュー「App」から「友だち紹介」を開き、「使う」にします
3. App の設定で「紹介した人に付けるポイント」「紹介された人に付けるポイント」（0〜10,000。空なら 500）と「1 人が 1 か月に紹介でポイントを受け取れる人数」（1〜100。空なら 10）を決めます
4. 会員はマイページの「友だちを紹介する」で自分のリンクを写す・LINE で送る・作り直すができます
5. 管理画面のメニュー「App」の下の「友だち紹介」で、確認待ち・注文・発送待ち・ポイントを付けた（付けたポイントの合計）・付けなかった（理由つき）を見られます。確認待ちの 1 件では「ポイントを付ける」「付けない」を選びます（取り消せないので、押す前にパスキーで本人を確かめます。「ポイントを付ける」はポイントを手で足すのと同じく「お金」の権限の人だけ、「付けない」は「運用」の権限から）。**名前やメールは出しません**（会員は ID の末尾 8 文字だけで、押すとお客さんの画面へ）

## ポイントが付く時

- リンク（`/p/referral/r/{印}`）を開くと、ブラウザに 30 日の印（Cookie。中身は印と開いた時刻だけ。暗号化）を置きます
- その方が 30 日のうちに**新しく会員になる**と、紹介を結びます。会員になる前に払われた注文がある方・もう紹介された方は対象外です
- 紹介された方の**最初に払われた注文**の受渡が全部発送された時に、2 人に付けます。2 回目からの注文では付きません。最初の注文が取消・返金で閉じたら、その紹介は終わりです
- 付けない時: 自分の紹介（同じメール・電話・届け先）、紹介した方の今月の上限を超えた、App を止めていた時の発送、ポイントを使わない設定、どちらかが会員でなくなった
- 確認待ち: 同じ紹介した方で、同じ接続元から 30 日のうちに 3 人目からは、店の人が選ぶまで付けません
- 取りこぼし（キューや受け手が落ちた時）は毎時 45 分の `referral:run` が拾います

## 守り

| こと | どうしているか |
|---|---|
| 2 度付けない | どの書き込みも連鎖のロックの中で紹介の状態を読み直す。紹介された人ごと・最初の注文ごとに一意の索引 |
| 自分を紹介させない | メール・電話のブラインドインデックスと、届け先（その場で復号してそろえた形。どこにも書かない）の重なりで断る |
| 大量に作った会員で取らせない | 払った最初の注文の発送まで待つ・月の上限・同じ接続元は確かめ待ち |
| リンクの印を当てさせない | 57 種 10 文字の乱数・接続元ごとの回数の上限・無い印でも同じ答え |
| Cookie を書き換えさせない | Laravel の暗号化で改ざんを断る・30 日はサーバーが中の時刻で数える・店の DB で引くのでほかの店の印は無いのと同じ |
| 個人情報を残さない | 表・イベントは台帳と注文の ID・数・決まった理由だけ。接続元は店の鍵の HMAC だけ |
