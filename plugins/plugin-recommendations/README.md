# おすすめのセクション（EC-SUGAR の App）

ページの編集の画面に「関連商品」「最近見た商品」「売れ筋ランキング」の区画を足す App です（ADR 0040 の区画の口。外から何も埋め込みません）。
並ぶのは、ショップに出ていて、いま買える商品だけです（下書き・売り切れ・公開を終えた商品は並びません）。見た目は核の区画「商品の並び」に合わせ、テーマの色で付きます（ADR 0071）。

## 使い方

1. 管理画面の店のメニュー「App」から「おすすめのセクション」を開き、「使う」にします。
2. ページの編集の画面の「区画を足す」で、3 つの区画を選べます（トップと自由なページ）。見出しと並べる数（4・8・12 個）、パターン（格子・横に流れる）を選びます。

| 区画 | 並ぶもの |
|---|---|
| 関連商品 | お客さんが最後に見た商品と同じカテゴリの商品。足りない分と、まだ商品を見ていないお客さんには新着 |
| 最近見た商品 | お客さんがそのブラウザで最近見た商品（新しい順）。まだ見ていないお客さんには出ない |
| 売れ筋ランキング | 直近 30 日にお支払いのあった注文で、売れた数の多い順。まだ売れていなければ出ない |

- 売れ筋は毎時 45 分の `recommendations:rank` が数え直します（払われずに期限で消えた注文・取消・返金の注文は数えません）。ショップの画面は数えた結果を読むだけです
- 商品の画面の下に関連商品を置く場所は、まだテーマの決まりにありません（ADR 0071 の「作って決めたこと」）

## 最近見た商品はブラウザにだけ覚えます

商品の画面を開くと、その商品の ID だけをお客さんのブラウザの Cookie（`sugar_recent`。ショップの鍵で暗号化、HttpOnly、30 日、20 件まで）に覚えます。会員でも、お店の側には誰が何を見たかを残しません。
読むときは書き換えられた前提で確かめます（長すぎる値は捨てる・商品の ID の形だけ・20 件まで・この店のショップに出ている商品だけ）。
