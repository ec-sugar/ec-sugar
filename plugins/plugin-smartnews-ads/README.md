# SmartNews 広告（App）

SmartNews の広告から来たお客さんが、ショップのページを見たことと、購入したことを SmartNews に知らせます（SmartNews Ads のピクセル）。広告の効果を確かめたり、広告の配信を良くしたりするのに使います。

## 使い方

1. EC-SUGAR の管理画面で店を開き、メニューの「App」を押す。一覧の「SmartNews 広告」の名前（か右の「設定」）を押すと、この App の画面に入る
2. 「設定」の「ピクセル ID」に入れて、「設定を保存する」を押す
   - ピクセル ID は、SmartNews Ads の広告管理画面の「イベント」タブで作ったピクセルの識別子です。「コードをダウンロード」で出るベースコードの `SmartnewsAds.p("…", "PageView")` の、最初の `"…"` の中にある英小文字と数字（20 文字ほど）を入れます
   - ほかの文字（ベースコードなど）は入れられません。コードを貼る必要はありません
   - 「使わない」のままでも先に保存できます。保存しただけでは動きません
3. 上の「この店では」の「使う」を押す
   - 切り替えと設定の保存は「運用」以上の権限の人だけで、押すとパスキーでもう一度確認します
4. 広告管理画面のイベントの設定で、「Purchase（購入）」をこのピクセルのイベントとして作っておく（URL の設定〔URL configuration〕で購入を数える設定は作らないでください。この App が完了の画面から送ります）

## いつ送るか

- 同意の帯は既定では出さないので、ショップを開いたときから送ります。管理画面の設定の「同意の帯」で「出す」にした店（海外のお客さんを相手にする店）では、お客さんが帯で「同意する」（広告の計測）を選んだあとだけ送ります（同意しないお客さんの分は送りません）
- トップ・商品の一覧と詳細・カート・特定商取引法の表記の画面で「ページの表示（PageView）」を送ります
- ご注文を受け付けた画面で「購入（Purchase）」を送ります。同じ画面を読み直しても、同じタブでは二度送りません
- ご注文の入力・確認、ご注文の状況、アカウントの画面には、タグを入れません

## 何が送られるか

- 見たページの URL、参照元、時刻、ブラウザと端末の情報（言語・時間帯・画面の大きさなど）、SmartNews の Cookie とローカルストレージの識別子
- SmartNews のアプリの中のブラウザで開いたときは、アプリの識別子
- 購入のとき: 合計の金額、通貨、品の ID と合計の数（注文の番号は送りません。ピクセルに受ける項目がありません）
- **送らないもの**: お客さんの名前・メールアドレス・電話番号・住所

送信先と送る情報は、ショップのフッターの「外部送信について」のページに自動で載ります。同意の帯を出す店では、お客さんはフッターの「Cookie の設定」からいつでも同意を変えられます。

## 知っておくこと

- 最初の注文のあとに、広告管理画面の「イベント」タブの「最後に受け取ったイベント（Last Event Received）」で、購入が金額つきで届いているかを確かめてください（金額の項目名は公式のページの中で `value` と `event_value` が食い違っていて、この App は値の表どおり `value` で送ります）
- 購入で送る品の ID は、このショップの商品の内部の ID です。ダイナミック広告（商品のカタログから広告を作る形）は、カタログの ID をこれとそろえる必要があり、ショップにはまだカタログを書き出す機能が無いので、今はふつうの広告（Standard Ads）の計測に使います
- SmartNews のピクセルは、識別子の Cookie をショップのドメインの上位のドメインにも書きます
