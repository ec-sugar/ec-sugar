# App「ラッピング・のし」（plugin-wrapping）

ご注文の時に、ラッピングの種類とのし（表書き・外のし／内のし・名入れ）を選べるようにする EC-SUGAR 公式の App（ADR 0078）。料金はご注文の合計に足し（税込み・消費税は 10%）、選んだ内容は注文の明細・納品書・配送の CSV に残る。核の「App が注文に料金の行を足す口」（`OrderChargeHandler`）の最初の使い手。

## 使い方

1. 管理画面のメニュー「App」で「ラッピング・のし」を使うにする
2. メニュー「App」の下の「ラッピング・のし」で「ラッピングの種類を追加」（名前 30 文字まで・料金 0〜100,000 円〔税込み〕・ショップで選べる）。20 個まで
3. のしを受けるなら、App の一覧の「ラッピング・のし」の設定で「のしを受け付ける」を入れる。表書きの選択肢（「、」区切りで 20 個まで。空なら 御祝、内祝、御礼、御中元、御歳暮、粗品、無地）・のしの料金（0〜10,000 円。空なら無料）・名入れの欄を出すか・名入れの文字数（1〜20。空なら 10）
4. 商品の画面の App の欄「ラッピング・のし」で「ラッピングできる」「のしを付けられる」を入れる
5. ショップの注文の入力に「ラッピング・のし」の欄が出る（カートに対象の商品がある時だけ）。確かめの画面の合計の欄に「ラッピング（リボン） ¥330」「のし（御祝・外のし・名入れあり） ¥110」

## 決まり

- **注文に 1 つ**: ご注文の商品をまとめて 1 つに包み、のしを 1 枚付ける。対象でない商品が混ざる時は「ラッピングできない商品（N 点）は、そのままお送りします。」を出す（品ごとに選ぶのは ADR 0078 の「後でやること」）
- **額はサーバーが決める**: 店の設定の料金を、確かめの画面と確定の錠の中で決め直す。確かめの後に料金・選択肢・のしの決まりを変えたら、その注文は確かめ直してもらう。お客さんの送った額は使わない
- **税と順番**: 料金は標準の率（10%）の調整の行（種類 `wrapping`・`noshi`）。ポイントの後・代引き手数料の前に足す（ポイントでは払えない。ギフトカードは使える。代引きの手数料の段は料金を含めた合計で決まる）。付くポイントの元には入らない。0 円の行も残す
- **名入れ**: 1 行・店が決めた文字数まで。`<` `>`・改行・制御文字・向きの印・幅の無い文字は断る。のしの表書きを選ばずに名入れだけは断る。店の鍵で暗号化して `wrapping_orders` に置く。記録（イベント）・注文の明細の名前・ご注文の状況・メールには入れない（「名入れあり」だけ）。中身が出るのは、入れた本人の確かめの画面・納品書・配送の CSV・管理画面の注文の「個人情報」（運用から・見た記録が残る）
- **納品書**（App「納品書・領収書」）: 店の人の画面の納品書のいちばん下に「備考: ラッピング: リボン／のし: 御祝・外のし・名入れ 鈴木一郎」
- **配送の CSV**（App「配送の CSV」）: B2 クラウドの「記事」とゆうプリR の「備考」に同じ 1 行（e飛伝とクリックポストの並びには自由な文の欄が無い）
- **贈り物**（App「贈り物」）のご注文でも選べる（送料の差額の返金はそのまま）
- **種類を直す・消す**: 受けたご注文の内容（その時の名前と料金）は変わらない。消すのは直前の再確認の後
- **やめる**: App を使うのをやめると注文の入力に欄が出なくなる。受けたご注文の行と記録は残り、納品書・配送の CSV の備考も出る

## 表

店の DB の `wrapping_types`（種類）・`wrapping_listings`（商品ごとの印。無い商品はどちらもできない）・`wrapping_orders`（注文ごとに選んだもの。種類の名前と額・表書き・掛け方・のしの額の写しと、暗号化した名入れ。追記だけで、DB のトリガーが直す・消すを断る）。書き込みは連鎖のロックの後に行のロックを取り、同じトランザクションでイベント（`wrapping.type_created`・`type_updated`・`type_deleted`・`listing_updated`・`recorded`。ID・料金・真偽・掛け方だけ）。

## 作り

| ファイル | 役 |
|---|---|
| `src/WrappingCharges.php` | 核の料金の口: 注文の入力の欄・見積もり（名入れの決まり）・確定の錠の中で残す・備考 |
| `src/NoshiRules.php` | のしの決まり（App の設定から） |
| `src/WrappingTypes.php` | 種類と商品の印を書く（連鎖のロックとイベント） |
| `src/WrappingAdminPage.php` | 管理画面の App の画面（種類の一覧・1 件・足す・直す・消す） |
| `src/WrappingListingPanel.php` | 商品の画面の欄 |

テストは `tests/Feature/Plugin/WrappingAppTest.php`（欄を出す条件・額と税と行の順・名入れの暗号化と出る所・断る値・選べない商品・指紋の食い違い・別の店・クーポンとポイントと代引きとギフトカードの重なり・贈り物・追記だけ）と `WrappingAdminTest.php`（種類と商品の欄・権限と店の境界・個人情報の入口）。
