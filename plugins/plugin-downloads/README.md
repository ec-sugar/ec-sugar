# App「ダウンロード販売」（ec-sugar/plugin-downloads）

PDF・音楽・動画・電子書籍・画像などのファイルを売る公式の App（ADR 0084）。

- 売る: 商品の扱い「ダウンロード」の商品を、ふだんのカートと注文の流れで（会員でもゲストでも。物と一緒のカートも）。送料なし・在庫なし（1 回の注文で 1 点まで）・受渡は digital。ダウンロードの品だけの注文はお届け先・贈り物・お届け日時を聞かない。コンビニ払いと代金引換は出さない
- ファイル: 商品の画面の App の欄「ダウンロード販売」の「ファイルを上げる」（1 商品に 5 つ・1 つ 500 MB まで・店の合計は運営の設定）。受け取りは核（8 MB の切れ端・拡張子と中身の型の両方を確かめる・実行できる形と HTML・SVG を断る）。保存先は写真と別の、外から直接は見えない `downloads`（`tenants/<店>/files/<ID>.<拡張子>`）
- 渡す: 払いが確かになったら（`PaymentConfirmed`）ファイルごとにリンク（既定 30 日・5 回。App の設定と商品の欄で変えられる）を作り、digital の受渡を渡し終え、「ダウンロードのご案内」のメールを送る。ご注文の確認の画面・マイページの「ダウンロード」・メールから開ける
- 開ける人: ご注文の確認の照会（注文番号＋メール）を通した人か、ログインした会員の本人だけ（メールのリンクだけでは開けない）。押すたびに錠の中で回数を数え、押したセッションに結びつけた 5 分の署名つきの道筋から `attachment`・`nosniff` で渡す
- 管理画面: App の画面「ダウンロード」と注文の画面に、ファイルごとの回数・最後の日時・期限。回数をリセット・期限を 30 日延ばす・ダウンロードを止める・再開する（運用の段階から。止めるは直前の再確認）。「ファイル待ち」（払う前にファイルを消された注文。置き直すと定期チェックで渡す。「今のファイルでリンクを送る」でもすぐ）
- 止める: 返金が確かになったら（返品・外でした返金の記録・銀行振込と代引きの返金の記録・払った後の取消）、全額ならリンクを全部、一部なら返したダウンロードの商品のリンク。物と一緒の注文は、送る品の発送の前なら払った後でも取り消せる
- 売らない: ファイルの無い商品と、App を止めた店の商品（カートに入らない・商品の画面は売り切れ）
- 定期チェック: 10 分ごとの `downloads:grant`（払われたのにリンクの無い注文に作り直す）、毎日 04:40 の `downloads:purge`（消したファイルを、渡したリンクの期限の後に保存先から消す）

App を止めると新しく売らないが、もう払ったお客さんはメールのリンク（照会の後）からダウンロードの画面とファイルを開ける（経路は `keptStorefrontRoutes`。ご注文の画面のリンクとマイページの入口は出ない）。
止めた店では、オーナーが App の画面の「この App のデータを消す」（か `php artisan plugin:purge <店> downloads`）で、リンク・商品ごとの期限と回数・売るファイルの行と、この店の保存先のファイルを消せる（ADR 0092。`src/DownloadDataPurger.php`）。お客さんがまだ受け取れるリンク（止めていない・期限の前・回数が残る）か、払われたのにまだ渡していない注文があるうちは断る。商品そのものは消さない。保存先の設定（`DOWNLOADS_MAX_FILE_MB`・`DOWNLOADS_SHOP_QUOTA_MB`）とバックアップは docs/install.md。
