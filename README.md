# EC-SUGAR

EC-SUGAR は、自分のサーバーで動かすネットショップの仕組みです。
ショップ・カート・支払い・発送・会員・管理画面を 1 つにまとめ、予約販売・ダウンロード販売・商品レビューなどは、店ごとに使う・使わないを選べる App で足します。
1 つのショップから、1 台のサーバーで複数の店を開く形まで、同じコードで動きます。

- 公式サイト: https://ec-sugar.jp/
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

## できること

- **ショップ**: 商品（種類・オプション・説明のブロック）、カテゴリ、カート、ご注文の確認、特定商取引法の表記、プライバシーポリシー、サイトマップ
- **支払い**: Stripe（カード情報はこちらのサーバーに一度も触れません）、銀行振込、代金引換、クーポン、ポイント、ギフトカード
- **注文のあと**: 発送・送り状番号・取消と返金・返品、注文の知らせのメール、納品書と領収書
- **会員**: メールのコードかパスキーでログイン、マイページ、届け先、退会
- **見た目**: 公式テーマ 4 つ。ページの区画を並べ替えて、トップや自由なページを管理画面で作れます（下書きとプレビューつき）
- **App**（店ごとに選ぶ）: 予約販売、ダウンロード販売、商品レビュー、お気に入り、おすすめ、メルマガ、お問い合わせ、カゴ落ちのお知らせ、再入荷のお知らせ、会員ランク、友だち紹介、ラッピング・のし、年齢確認、LINE 連携、商品フィード、配送の CSV、お知らせ・ブログ、解析と広告のタグ など
  - 定期便・予約・デジタルチケット・抽選販売の App は、1.0 の公開には入っていません。文書やコードのコメントにこれらの App の名前が出てくることがありますが、App そのものはこのリポジトリに含まれません
- **管理画面**: パスキーだけでログイン、オーナーとスタッフの権限、店ごとの閲覧・運用・お金の段階
- **守り**: 店ごとに DB とロールを分ける、個人情報の列の暗号化、管理画面からコードを入れられない、読み取り専用のイメージ、追記だけの記録とハッシュの連鎖。詳しくは [docs/security/threat-model.md](docs/security/threat-model.md)

## 入れ方

Ubuntu のサーバー 1 台に、インストーラーで入れます。DNS に 2 行を足し、`sudo ./deploy/install.sh` のウィザードに答え、最後に出るアドレスでパスキーを登録すれば、管理画面に入れます。

```sh
git clone https://github.com/ec-sugar/ec-sugar.git ~/ec-sugar
cd ~/ec-sugar
git checkout v1.0.0
./deploy/install.sh --check   # 先に確かめるだけ（何も変えない）
sudo ./deploy/install.sh
```

準備するもの（サーバー・ドメイン・管理画面に入る接続元）と、複数の店の形・既にある Web サーバーの後ろに置く形・Cloudflare Tunnel で出す形は [docs/install.md](docs/install.md) にあります。
