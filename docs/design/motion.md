# 動き（アニメーション）の決まり

ショップと管理画面の動きの共通の決まり。部品の使い方は、ショップは [theme-api.md の「動き」](theme-api.md)、管理画面は [admin-ui.md の「動き」](admin-ui.md) を見る。

- 由来: 2026-10-30 の運営の判断で、今あるテーマと管理画面にアニメーションを足すことにした → 強さはテーマごとに変える、場所は商品まわり・カートとメニュー・ページを開いた時・管理画面
- 使うもの: CSS（transition・@keyframes）と Motion（ショップは `motion/mini`、管理画面は `motion-v`）。新しいライブラリは [ADR 0037](../adr/0037-JavaScriptのライブラリは基準を満たせば採る.md) の基準を通してから

## 何のために動かすか

動きは「何が変わったか」を見せるために使う。飾りのために動かさない。

| 動かす | 動かさない |
|---|---|
| 押した・開いた・選んだ・保存した、の応え | 何もしていないのに動き続けるもの（点滅・回り続ける飾り） |
| 種類やオプションを選んで、写真や価格が変わったこと | 文を 1 文字ずつ出す、数字を数え上げる |
| カートに入ったこと、数が変わったこと | 支払い・注文の入力と確認の画面の飾り（個人情報の画面は静かに） |
| ページを開いた時の 1 か所だけの出る動き | 見出し・段落・カードのすべてに付けた「下から浮かぶ」 |

## 強さ

| 強さ | 使う所 | 長さ | 移動 |
|---|---|---|---|
| 控えめ | 管理画面、角砂糖、kinari | 0.15〜0.3 秒 | 数 px まで。大きさは 0.97〜1 |
| しっかり | fashion、botanica | 0.3〜0.6 秒（スクロールで出るカードは順に 0.05 秒ずつずらす） | 十数 px まで。写真の拡大はゆっくり 1.05 まで |

- テーマが強さを宣言し、コアの動きの部品がそれを読む（書き方は theme-api.md）。テーマを作るときは、まず控えめで作り、テーマの性格に合う所だけ強くする
- イージングは、出る・開く時は減速（ease-out）、消える・閉じる時は加速（ease-in）。跳ねる動き（バネ）は押した手ごたえだけに使う

## 必ず守ること

1. **動きを減らす設定の人には動かさない**。`prefers-reduced-motion: reduce` で CSS の動きを止め、JS の動きも始めない（管理画面は `MotionConfig` の `reducedMotion="user"`）。状態は変わるが、移り変わりの途中を見せない
2. **transform と opacity だけを動かす**。幅・高さ・位置（top・left）・余白を動かさない（レイアウトがずれる・重くなる）。開き閉じで高さが変わるものは、中身を transform と opacity で出し、高さは一度で変える
3. **中身が見えない時間を作らない**。JS が動かない・読み込みが遅い時も最初から見える。スクロールで浮かぶ動きは「JS が印を付けた要素だけ最初を隠す」形にする
4. **操作を待たせない**。動きの途中でも次の操作を受ける。押してから応えるまで 0.1 秒を超えない
5. **CSP と Trusted Types の下で動く形で書く**。インラインの script、style 属性の文字列、innerHTML、eval を使わない。JS から見た目を変える時は CSSOM（要素の style の項目）か Web Animations で
6. **テーマに JS を入れない**。ショップの動きの JS はコアの部品に置き、テーマは CSS とデータ属性で選ぶ（テーマに JS を足す仕組みは 開発者モードで別に決める）
7. **ブラウザのテストを動きで不安定にしない**。テストは動きを減らす設定で実行する（Playwright の `reducedMotion: 'reduce'`）

## 新しい動きを足す時の確認

- [ ] 何が変わったかを見せる動きか（飾りでないか）
- [ ] 長さと移動が上の「強さ」の範囲か
- [ ] 動きを減らす設定で止まるか（macOS は「アクセシビリティ → ディスプレイ → 視差効果を減らす」で試せる）
- [ ] JS を切っても中身が見えるか
- [ ] transform と opacity だけか
- [ ] 個人情報の画面に足していないか
- [ ] CSP の違反がブラウザの開発者ツールに出ていないか
