# ショップでよく入れられる JavaScript の整理

タグの連携の Appと開発者モードの線引きの土台（2026-10-29。ショップによく入れられる JavaScript を一度まとめておくため）。宛先（許すドメイン）の細かいところは、作るときに各社の公式の資料で確認する。

## 種類

| 種類 | 例 | 注意 |
|---|---|---|
| 1. 計測・広告のタグ（ID を入れるだけ） | GA4・Google 広告・Meta ピクセル・LINE タグ・Yahoo! 広告・TikTok ピクセル・X ピクセル・Microsoft Clarity・ヒートマップ（User Heat・Hotjar） | 購入の記録に名前やメールを送らない。ヒートマップは入力欄の中身を記録しない設定 |
| 2. 何でも入れられる「箱」 | Google タグマネージャー・KARTE・b→dash | 任意のスクリプトが動く。そのツールのアカウントを取られると、ショップに好きなスクリプトを入れられる |
| 3. 画面に部品を出す | チャット（Channel Talk・チャットプラス・Zendesk・Intercom）・レビュー（ReviCo・Yotpo）・SNS の埋め込み（Instagram・YouTube）・ロボット除け（reCAPTCHA・Turnstile） | 会話やレビューに個人情報が入る・表示の XSS・宛先が多い |
| 4. アフィリエイト | A8.net・バリューコマース・楽天アフィリエイト | 購入の完了の画面で注文の番号と金額を送る |
| 5. 決済のボタン | Amazon Pay・PayPay・Apple Pay | 支払いの画面に入る。コアの決済のドライバで扱う |

ブラウザを通さない送り方（Meta の Conversions API・Google の Measurement Protocol・LINE の CAPI）は、ショップに JavaScript を入れないのでいちばん安全で、広告ブロックにも左右されない。

## 線引き（案）

| 扱い | 中身 |
|---|---|
| タグの連携の App（最初） | 1 の計測・広告のタグ。ID だけを入れる（形を確認する）。同意の通知。購入の完了の計測は金額と注文の番号だけ |
| 同じ App の次の段 | サーバーから成果を送る形 |
| 別の App | チャット・レビュー・SNS の埋め込み・アフィリエイト |
| 開発者モードだけ | 2 の「箱」（任意のスクリプト） |
| コア | 決済のボタン・ロボット除け |
| どれも入れない画面 | 注文の入力と確認・お客さんのアカウント（ロボット除けを除く） |
