# 0047 ショップで JavaScript を動かせる者を 1 枚の表で決める

状態: **採用**（2026-10-31。決めることの 3 つは運営が選択肢で決めた: サーバーに入れたテーマ・App は印なしで JS を持てる・GTM は作らない・SaaS の他社の App は審査した App だけ）。ADR 0015・0020・0028・0034・0037・0039・0040・0041 と theme-api.md の線引きをそろえる。開発者モードはこの表の中で決める

## 要点（先に）

ADR の見直し（2026-10-31）で、公式テーマ・他社の App・制作会社のテーマ・GTM（Google タグマネージャー）が JS を持てるかが、文書ごとに食い違っていた。次の 2 つの線で決める。

1. **誰が書いたか**: サーバーに入れる人（composer）が入れたものは、もう PHP を書ける信頼の高さなので JS も持てる。管理画面から入れるもの（店の人）は動くコードを持てない（CONCEPT 7.2）
2. **どの画面か**: 個人情報の画面（支払い・注文の入力と確認・お客さんのアカウント）では、核の JS だけを動かす（入力を盗む型の攻撃を防ぐ）

## 表

| 誰 | ふつうの画面 | 個人情報の画面 | 根拠 |
|---|---|---|---|
| 核 | 動かせる | 動かせる | 審査した自分のコード |
| 公式テーマ | 別のファイルの JS を持てる | 動かさない | ADR 0020・0028 |
| 自分で持つ形でサーバーに入れたテーマ・App（制作会社など） | 別のファイルの JS を持てる（印は要らない） | 動かさない | composer で入る＝PHP も書ける |
| SaaS・マーケットの他社のテーマ | 持てない | 動かさない | ADR 0020（コードを含まない形） |
| SaaS の他社の App | 審査した App だけ、決まった読み込み（`storefront.scripts`）で持てる | 動かさない | ADR 0025・0034 |
| 店の人（管理画面から） | 持てない。HTML は許した形だけ | 持てない | CONCEPT 7.2・ADR 0041 |
| 外の埋め込み（動画・地図） | 決まった宛先の iframe だけ（sandbox） | 置かない | ADR 0040 |
| 外のタグ（解析・広告） | タグの App の決まった読み込みだけ | 読まない | ADR 0034 |
| GTM（何でも入る箱） | 作らない | 読まない | 店の人が管理画面の外から何でも入れる道になる |

## 決めたこと（2026-10-31）

1. 自分で持つ形でサーバーに入れたテーマ・App の JS: 開発者モードの印なしで持てる（入れる時点で PHP まで書けるので、JS だけ止めても守りにならない）。開発者モードは「外のサーバーのスクリプトを読む宛先を店の設定で足す」ことだけに絞る
2. GTM: 作らない。GTM は店の人が管理画面の外（Google の画面）から何でも入れられる道になり、CONCEPT 7.2 と 1 の線を両方くぐる。要るタグは App にする
3. SaaS の他社の App の JS: 審査した App だけ、ふつうの画面で持てる。審査の決まりは、他社の App を受け付ける前に別の ADR で決める

## そろえる文書

- theme-api.md の「テーマは JS を書かない」（627・833 行）を、この表の「公式テーマ・サーバーに入れたテーマは別のファイルで持てる。他社のテーマは持てない」に合わせる
- ADR 0039 の「テーマに JS を入れない決まりと同じ」（126 行）、ADR 0040 の「他社の App はテーマと同じく JS を持てない（ADR 0020）」（61 行）に、この ADR への印
- 外のタグの中身の基準（LINE の `eval`・X の `new Function`。tag-apps.md）は、ADR 0037 の「eval を使わない」をタグにも当てるかを、タグの App を足す時に決める

## 結果

- 開発者モードの出発点が決まる
- 個人情報の画面の守りが、どの JS にも同じ 1 本の線になる
