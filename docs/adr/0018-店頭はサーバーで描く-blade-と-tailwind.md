# 0018 店頭はサーバーで描く（Blade と Tailwind）

状態: 採用（2026-10-27）。一部置き換え（→ ADR 0028: テーマ API を 2 に上げ、トップなどの中身はテーマが宣言した区画で持つ。→ ADR 0034: 「店頭に外部のスクリプトは要らない」を、App のタグに限って置き換え〔App のパッケージの同じオリジンのファイルと、宣言した宛先だけ。個人情報の画面には入れない〕。→ ADR 0039: ページは区画を積んで作り、編集の画面で並べる）

## 文脈

管理画面（運営の画面）の骨組みができ、次は店頭（お客さんが見る画面）を作る。買取は後回しにし、通常の EC（商品を見る → カート → 注文 → 支払い）を先に作る（運営の判断）。
店頭は検索エンジンに載り、初めて来た人にも速く出る必要がある。本番で Node.js を常駐させない（ADR 0015）ので、Node.js でのサーバー描画（SSR）は使えない。
将来、外部の人がストアのテーマを作る。Tailwind があると扱いやすい（ADR 0017 の文脈）。

## 決定

- **店頭は Laravel の Blade でサーバーが HTML を描いて返す**。SPA にしない。JavaScript は、無くても使える作りに少しだけ足す（数量の増減など）
- **CSS は Tailwind CSS v4**。トークン（CSS の変数）を店頭用に持ち、テーマはトークンと Blade のテンプレートを差し替える。ビルドはビルドの時だけ（Vite）
- **テーマは composer のパッケージ**（`plugins/` と同じ配り方）。管理画面からテーマのコードを入れない（CONCEPT 7.2）。テーマが受け取る画面とデータの約束は「テーマ API」としてバージョンを付ける（第 1 バージョン: [docs/design/theme-api.md](../design/theme-api.md)。→ ADR 0028 で 2 に上げた）。テーマは DB に触らない
- 店頭の経路は公開が基本。全経路の検査（`RouteAudit`）は「公開の印と理由」を求め続け、カート・注文など状態を持つ経路の規則を足す
- 店頭の CSP はインラインの script を許さない（`script-src 'self'`）。支払いは Stripe の画面へ移る形（ADR 0019）なので、店頭に外部のスクリプトは要らない → ADR 0034 で一部置き換え（タグの App が、宣言した宛先だけを CSP に足して読み込む。Trusted Types の関所は核が作る）
- 店頭の入口にも、壊れた文字・NUL 文字の拒否を掛ける

## 結果

- 得たもの: 検索エンジンに載り、最初の表示が速い。PHP だけで動く（導入先の条件が変わらない）。テーマを作る人は Blade と Tailwind を知っていればよい
- 失ったもの: 管理画面（Vue）と店頭（Blade）で部品を共有できない（見た目のトークンの考え方だけ共通にする）。画面の中の細かい動きは、JavaScript を足す分だけ手間がかかる

## 作って決めたこと（ショップの本文、2026-11-06。システム全体の見直し）

- **ショップは JSON の本文を受けない**。ショップの画面と核のスクリプト（カート・お気に入りなど）が送るのはフォームの形だけで、Content-Type が JSON の要求は、店を引いた後（知らないホストは先に 404）・CSRF と壊れた文字の拒否の前に 415 で断る（`App\Storefront\Http\Middleware\RefuseJsonBody`）。JSON を受けるのは本文を生のまま読んで署名を確かめる通知だけ: Stripe はセッションの無い群（storefront-media）なので通らず、App の Webhook（LINE 連携）は経路で外す
- **本文の大きさ**: 入口の nginx はふだん 1m（ショップ・通知・管理画面のログイン）。管理画面のホストの API だけ 12m（写真・App の取り込み）、商品の CSV の口だけ 100m（ほかのホストは 404）。開発の nginx も同じ形で、`docker/check-compose.sh` が見る
- **JSON の大きさは PHP の入口で**: Laravel は要求を作る所（`Request::capture()`）で JSON を丸ごと読み解くので、ミドルウェアでは間に合わない。`public/index.php` が先に `App\Http\JsonBodyLimit::guard()` を呼び、2 MB を超える JSON を Content-Length で（見出しが無ければ上限 + 1 バイトまで読んで）413 にし、Laravel を起こさない。前は 12 MB の JSON でメモリを使い切らせて 500 にできた（回数の制限より前に効くため）
