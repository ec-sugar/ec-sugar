# 0004 API 中心（管理画面も店頭も API 経由）

状態: 採用（2026-10-27）

## 文脈

よくある設置型の EC は管理画面と店頭が密結合で、テーマの差し替えとアップグレードが難しい。
受託では店頭デザインの差し替えが売り物になる。AI エージェントが買い手・運営者になる流れもある。

## 決定

核は API でのみ操作する。管理画面（SPA）も店頭（テーマ）も API 経由。
テナント DB への経路を API の認可一点に絞る。後から MCP サーバーもこの API の上に載せる。

## 結果

- 得たもの: 店頭を差し替え可能にして受託単価を上げる。攻撃面が「API の認可」と「1 テナント分の DB」に限定される。エージェント対応が自然に出る
- 失ったもの: Blade で画面を直接描く速さ。管理画面の拡張をプラグインが行う手段を別途設計する必要（ADR 0005）
