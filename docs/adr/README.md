# ADR（Architecture Decision Record）

設計上の「決定」を 1 件 1 ファイルで記録する。全体像は [../CONCEPT.md](../CONCEPT.md)、個別の決定とその理由はここ。

- 番号は連番。ファイル名は `NNNN-短い-題名.md`
- 状態は `提案中` → `採用` → `置き換え（→ NNNN）` / `廃止`。一部だけを覆したときは `採用（一部置き換え → NNNN）` にし、元の ADR の状態の行に「何を」置き換えたかを書く。本文の歴史は消さず、該当の文の後ろに「→ ADR NNNN で置き換え」と添える
- 決定を覆すときは、元の ADR を消さずに新しい ADR を書いて「置き換え」にする（経緯が残る）
- 書くのは「文脈」「決定」「結果（得たもの・失ったもの）」の 3 つだけ。長くしない
