# 0001 ADR を使う

状態: 採用（2026-10-27）

## 文脈

設計の議論は docs/CONCEPT.md に集約しているが、CONCEPT は全体像を描く文書で、
「なぜそう決めたか」「何を捨てたか」が後から辿りにくい。長く続く開発では、決定の経緯が
失われると同じ議論を繰り返す。

## 決定

設計上の決定を ADR として 1 件 1 ファイルで記録する。CONCEPT.md は全体像、ADR は個別の決定。
決定を覆すときは新しい ADR で「置き換え」にし、元は残す。

## 結果

- 得たもの: 決定の理由と代償が残る。新しく入る人（将来の自分を含む）が経緯を追える
- 失ったもの: 決定のたびに短い文書を書く手間
