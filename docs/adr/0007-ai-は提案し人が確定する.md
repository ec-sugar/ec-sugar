# 0007 AI は提案し、人が確定する

状態: 採用（2026-10-27）

## 文脈

AI 機能は必須。ただし査定額・出品審査・マッチングには法的責任（古物営業法、景表法）が伴い、
個人情報（本人確認書類）を外部 LLM に送ることには同意の問題がある。

## 決定

- AI は提案まで。確定は人。提案と確定の両方をイベントとして残す（どのモデルの何バージョンが何を言い、人が何に確定したか）
- 核は AI を知らない。LLM はドライバ型プラグイン（Claude API を第一、Ollama は開発・検証）、機能は AI プラグイン
- 個人情報は既定で外部 LLM に送らない。テナントが明示的に有効化した場合のみ
- MCP サーバーをチャネルの一つにする（テナントが自分のエージェントから基盤を操作できる）

## 結果

- 得たもの: 説明責任。AI の提案と人の確定の差分がそのまま評価データと相場データの種になる。「自分のデータを自分のエージェントに使わせる」という差別化
- 失ったもの: 完全自動化による省力化の一部
