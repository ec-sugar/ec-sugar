# 0097 店の人はテーマが用意した色の組から選び、主な色だけ自由に決める

状態: **採用**（2026-11-12。色の自由さは運営が選んだ〔「組から選ぶ＋主な色は自由」〕。案の形も運営が選んだ〔「この形で作る」〕。中身は作る時に決めた）。
ADR 0028（テーマは区画を宣言し、核は汎用の値と写真を持つ。「テーマは色・文字・角の丸みなどの見た目の値〔CSS の変数〕を宣言し」「バージョンは……見た目の値〔色・文字・角の丸み〕だけを持つ」）の見た目の値の部分を、形にする。ADR 0039（ページの編集の画面）の上に足す。置き換えるものは無い

## 要点（先に）

1. テーマは `theme.json` の **`style`** で、店の人が選べるものを宣言する: **色の組**（2〜6 つ）・**主な色を自由にするか**・**字の組**（1〜4 つ）・**角の丸み**（1〜3 つ）
2. 店の人が持つのは**選んだものの名前と、主な色の 1 色だけ**（`#rrggbb`）。CSS の値そのものは持たない。値はテーマのバージョンの下書きと公開（`theme_versions.draft` / `published` の `style`）に入るので、**下書き・公開・バージョンの複製は今の仕組みのまま**
3. ショップは公開した値から**小さな CSS のファイル**（`:root { --color-…: … }`）を作り、テーマの CSS の後に読む。**CSP（`style-src 'self'`）は緩めない**（インラインの style は使わない）
4. 主な色からボタンの文字の色（白か黒）と押したときの色を**核が計算する**。読みにくい組み合わせ（コントラストが 4.5 : 1 に満たない）は保存は通し、**画面で知らせる**（止めない）
5. 編集はページの編集の画面の左の欄に**「見た目」**の札を足し、真ん中の本物のプレビューにすぐ映す

## 文脈

- 11-11 に公式の店（official.ec-sugar.jp）を角砂糖で作ったとき、色を変えられなかった（黒と白だけ。公式サイトの藍に合わせられない）。
- 公式テーマ 4 つは、色と字を CSS の変数（Tailwind v4 の `@theme` の `--color-*`・`--font-*`）と、核の区画のための `--sugar-radius`・`--sugar-button-radius`・`--sugar-heading-font` などで決めている（ADR 0039）。変数の名前はテーマごとに少し違う（kinari・fashion・botanica は `--color-band-strong`・`--color-sage-band` などを持つ）
- ショップの CSP は `style-src 'self'`・Trusted Types。インラインの `<style>` も `style=` も使えない（ADR 0041 の整えた HTML も同じ CSP の下で描く）
- 色を全部自由にすると、読めない店（薄い灰色の地に白い字など）を作りやすい。組だけだと、自分の色（公式サイトの藍）に合わせられない。運営は間を選んだ

## 決定

### テーマの宣言（`theme.json` の `style`）

```json
"style": {
  "palettes": {
    "mono":   { "label": "白と黒", "colors": { "canvas": "#ffffff", "band": "#f6f6f7", "ink": "#18181b", "accent": "#18181b" } },
    "indigo": { "label": "藍",     "colors": { "canvas": "#ffffff", "band": "#f3f5fa", "ink": "#1a1f36", "accent": "#283593" } }
  },
  "accent": true,
  "fonts":  { "gothic": { "label": "ゴシック" }, "mincho": { "label": "明朝" } },
  "radius": { "square": { "label": "四角" }, "soft": { "label": "少し丸く" } }
}
```

- **色の組の色の名前**は、テーマの `@theme` の `--color-<名前>` のうち、テーマが組で変えてよいとしたもの。核が知っている名前（`canvas`・`band`・`line`・`ink`・`ink-muted`・`ink-soft`・`accent`）に加え、テーマが `style.tokens` で足した名前（例 kinari の `sage-band`）だけ。値は `#rrggbb` だけ（登録で確かめる。知らない書き方は登録しない。ADR 0028 の宣言と同じ扱い）
- 最初の組が既定。`style` を宣言しないテーマは、今までどおり何も選べない（テーマ API 2 のまま足せる。付け足しなので版は上げない。ADR 0093）
- **字の組と角の丸みの中身（書体の並び・rem の値）は、テーマの CSS が持つ**。`theme.json` は名前と表示の名前だけ。核は選んだ名前を `<html data-sugar-font="mincho" data-sugar-radius="soft">` で渡し、テーマの CSS が `[data-sugar-font="mincho"] { --font-sans: … }` で受ける。書体のファイルはテーマが同梱するもの（自分のオリジン）だけ。外の書体の配り先は使わない（CSP と外部送信の公表を増やさない）

### 店の値（バージョンの下書きと公開）

- `theme_versions.draft.style` / `published.style` = `{ "palette": "indigo", "accent": "#1e3a8a" | null, "font": "mincho", "radius": "soft" }`
- 確かめ（保存のとき）: 名前はそのテーマの宣言にあるものだけ、`accent` は `^#[0-9a-f]{6}$` だけ（小文字にそろえる）、`accent` を許さないテーマでは null だけ。宣言から消えた名前は描くときに既定へ戻す（テーマの更新で組が減っても壊れない）
- 書き込みは今のテーマの中身の書き込みと同じ道（`ThemeContentService`・`EventStore::lock()`・改訂の番号で同時の編集を断る・イベントを同じトランザクションで）

### ショップへの出し方

- 新しい経路 `GET /theme/style-{印}.css`（公開。理由: テーマの見た目の値だけで、個人情報も店の秘密も含まない）。印は公開した値の短いハッシュで、変わると URL が変わるので長くキャッシュできる（`Cache-Control: public, max-age=31536000, immutable`）
- 中身は `:root{--color-canvas:#ffffff;…}` だけ。**値は確かめた `#rrggbb` と核が計算した色だけを書き、店の人の文字をそのまま CSS に入れない**（CSS の注入を作らない）
- レイアウトはテーマの CSS の `@vite` の**後**に `<link rel="stylesheet">` で読む（核の部品 `<x-storefront::theme-style />`。テーマはレイアウトに 1 行置く。置かないテーマは色が変わらないだけで壊れない）。値が既定と同じなら link を出さない
- プレビュー（編集の画面の真ん中）は、署名つきの道（`secret-link`）で下書きの値の CSS を返す

### 主な色から計算する色

- `--color-accent` = 店の人の色
- `--color-on-accent` = 白か黒の、主な色に対してコントラストが高い方
- `--color-accent-hover` = 主な色を少し暗く（明るい色なら少し明るく。OKLCH で明るさを ±8%）
- 知らせる（止めない）: 主な色と地（`canvas`）のコントラストが 3 : 1 に満たない（ボタンの縁が見えない）・白でも黒でも主な色の上の文字が 4.5 : 1 に満たない。「読みにくいかもしれません」と画面に出す。方針（2026-10-30「手間はお客さんに掛けない」）どおり保存は止めない

### 管理画面

- ページの編集の画面の左の欄の上に「区画」と「見た目」の札。「見た目」に、色の組（色の見本の丸を並べた札から選ぶ）・主な色（色を選ぶ部品と `#` の欄。「組の色に戻す」）・字の組・角の丸み
- 変えると下書きに自動で保存し、プレビューの CSS を読み直す（ページを描き直さない）
- 権限は今のテーマの中身と同じ（読むのは閲覧、変えるのは運用）

## 作る順（区切り 2 の中）

1. 宣言の読み込みと確かめ・店の値の保存と確かめ・CSS の経路（テストで: 知らない名前・壊れた色・注入の形を断る、公開した値だけが出る、宣言から消えた名前は既定へ）
2. 公式テーマ 4 つに `style` を書く（各 3〜4 つの色の組、角砂糖は藍を含める）・レイアウトに 1 行
3. 管理画面の「見た目」の札とプレビューへの即時の反映・コントラストの知らせ（ブラウザのテスト）
4. 文書（theme-api.md・お店の人向けの使い方・公式サイトの「できること」）と、公式の店を藍にする

## 採らなかった案

- **色を全部自由に**: 読めない店を作りやすい。運営が間を選んだ
- **インラインの `<style>` に nonce を付ける**: ショップの CSP の形を変えることになり、キャッシュも効かない。ファイルにすれば CSP はそのまま
- **店の人の CSS を入れる欄**: 管理画面からコードを入れない（CONCEPT 7.2）。ADR 0041 のカスタム区画も CSS は入れない
- **外の書体の配り先（Google Fonts など）を選べるように**: 外部送信が増え、CSP を広げることになる。書体はテーマが同梱する

## 守り

- CSS に出すのは、確かめた `#rrggbb`・核の計算の結果・テーマの宣言の名前（`[a-z][a-z0-9-]` に限る）だけ。店の人の自由な文字は CSS に入らない
- 公開の経路は公開した値だけ。下書きはプレビューの署名つきの道だけ（今のプレビューと同じ守り）
- 店の境界: 値は店の DB のテーマのバージョンの行。経路は店のホストの下だけで、ほかの店の値を読む道は無い

## 作って決めたこと（2026-11-12、区切り 2「色・字・角の丸み」）

- **組に要る色**: どの組も `canvas`・`ink`・`accent` を必ず書く（主な色の読みやすさを地と比べるため）。ほかの色（`band`・`line`・テーマの `tokens`）は組ごとに書いても書かなくてもよく、書かなかった色はテーマの CSS の値のまま。`on-accent`・`accent-hover` は核が計算するので、組にも `tokens` にも書けない。`tokens` は 8 つまで、表示の名前は 1〜20 文字。字の組と角の丸みは書かなくてよい（書けば 1〜4 つ・1〜3 つ）
- **最初の組はテーマの CSS と同じ色**: 何も選ばない店（最初の組で主な色も組のまま）には CSS を出さないので、最初の組はテーマの `@theme` と同じ値にする。公式テーマ 4 つでそうなっていることと、どの組も文字が 4.5 : 1・主な色が地の上で 3 : 1 以上であることを `tests/Unit/ThemeStyleTest.php` が見張る
- **CSS の中身**: 組の色を宣言の順に、その後に主な色（店の色か組の色）・`on-accent`・`accent-hover` を書く。組の主な色のままでも計算した 2 色は書く（組を替えたのに押したときの色がテーマの既定のまま、にしない）。印は CSS の中身の sha256 の頭 16 文字（テーマの更新で組の色が変わっても URL が変わる）。書く前に名前と値の形をもう一度確かめ、外れたら止める（`ThemeStyleSheet`）。印の合わない要求は中身の無い 404・`no-store`（古い HTML が古い印を指しても、テーマの色に戻るだけ）
- **計算**: `on-accent` は白と黒のコントラストの高い方（同じなら白）。WCAG 2 の相対輝度で、どの色でも高い方は 4.58 : 1 以上になるので、「主な色の上の文字」の知らせ（`text_on_accent`）はふつう出ない（計算を変えたときの見張りとして残した）。`accent-hover` は OKLab で明るさだけを 0.08 動かす（`on-accent` が白の色は暗く、黒の色は明るく）。sRGB の外に出た分は 0〜1 に詰める（色相の保ち方は簡単なもので十分とした）
- **字と角の受け渡し**: `<html>` の属性はテーマが外枠に書く（`data-sugar-font="{{ $themeStyle->font ?? '' }}"`）。核の部品は `<head>` の中に置くので `<html>` に属性を足せないため。`$themeStyle`（`ThemeStyleView`）はすべての画面に渡し、核の部品は同じ値を要求から読む（部品に PHP のコードを書かない決まりのため `ThemeStyleView::current()`）。公式テーマは「準備中です」の画面にも同じ 2 か所を置いた
- **経路**: 公開の CSS は写真と同じセッションを持たない群（`storefront-media`）に置いた（Cookie を付けず、準備中のショップの「準備中です」の画面もテーマの色で描くため。中身は色だけ）。下書きの CSS は `/preview/themes/{テーマ}/style.css`（同じ群・秘密の道筋の宣言）。署名は画面のプレビューと同じ形で、範囲は店・テーマ・期限（ページは問わない）、鍵の用途は別（`storefront-theme-style-preview`）。画面のプレビューのリンクと同じ期限で、プレビューの画面を描くときに道筋を置く
- **プレビューへの映し方**: 編集の画面は見た目を保存したら枠の中へ `{ type: 'style', revision, font, radius }` を知らせ、`editor.js` が下書きの CSS の `<link>` を `r=<改訂>` つきで作り直し、読めてから古い方を外す（読む間に色が抜けない）。リンクの期限が 3 分を切っていれば枠ごと読み直す。下書きのプレビューでは、既定の値でも CSS の `<link>` を必ず置く（読み直す口を作るため。中身は空）
- **保存の順番**: 見た目の保存は区画の保存と同じ順番待ちに並べる（どちらもバージョンの改訂を 1 つ進めるので、並べないと 409 になる）。見た目の変更は 0.4 秒待って保存（区画の 0.8 秒より短い。押して選ぶ操作が多いため）。「公開する」と画面を離れる時は、見た目の待っている保存も先に済ませる
- **DB でも守る**: 移行 `2026_11_12_100000_check_theme_versions_style` で、下書きと公開の `style` は `{ palette, accent, font, radius }` だけ・名前の形・主な色は `#rrggbb`（小文字）か null を検査の関数 `sugar_theme_style_ok` で止める（アプリの確かめをすり抜けても、CSS に出る値の形をここで止める）
- **記録**: `theme.style_saved` に、選んだ組・字・角の名前と「主な色を自分で決めたか」（`custom_accent`）だけを残す（色の値は残さない）。公開は今までの `theme.published`
- **公式テーマの組**: 角砂糖は白と黒・藍（公式サイト ec-sugar.jp の CSS の変数 `--ai: #3451b2` と文字の `#0e1330` に合わせた）・桜・抹茶、kinari は生成り・墨と白・藍染め、fashion はモノトーン・グレージュ・ネイビー、botanica はセージ・テラコッタ・深い森。字は端末の書体（明朝は Hiragino Mincho・Yu Mincho）で、新しい書体のファイルは足していない。角は核の区画の変数（`--sugar-radius`・`--sugar-button-radius`）と、角砂糖では Tailwind の `--radius-lg`・`--radius-xl`・`--radius-2xl` も替える
- **まだのこと**: 作る順の 4 のうち、お店の人向けの使い方（ec-sugar.jp/docs/shop/）・公式サイトの「できること」・公式の店を藍にする、は別に行う（公式サイトの元は別のリポジトリのため）
